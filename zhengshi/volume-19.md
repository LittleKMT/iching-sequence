## 鼎卦

### 鼎卦巽下離上

### 宣聖講義

| 原文 | 白話文 |
|---|---|
| 鼎上離下巽。巽為木。木火同功。曰鼎。一則本鑽木取火。供民熟食之義。一則明以薪資火。為鼎烹飪之象。故卦取巽離之合。上離火而下巽木。巽又為風。木者。生火之原。風者。助燃之物。故巽在離下。 | 鼎卦上離下巽。巽為木，木火相資而成鼎義：一是追溯鑽木取火、教民熟食，二是薪木供火、鼎中烹飪之象。上為離火，下為巽木；巽又為風，木能生火，風能助燃，所以巽居離下。 |
| 示為烹飪之本也。鼎者器名。而卦義重在其用。亦如井卦取養民之用為義。鼎之用亦為生養之需。人自有火以後。未有不資于烹飪以為食。即未有不賴于鼎鑊以為生。縱夷蠻之民。尚有不熟食者。不足以為法。故鼎養。 | 表示烹飪根本。鼎雖是器名，卦義重其功用，如井卦重養民。人有火後便靠烹飪取食、靠鼎鑊生活；仍生食的族群不能作常法，所以鼎養也是民生不可缺。 |
| 亦民生不可離者。鼎之為物。金也。其成用。則水火與木。其所藉。則土也。是一物備五行之德。而水火主其要焉。故卦本乎離。與井之本乎坎水者。恰相對。其下皆巽。巽則水可以升。火可以伏。一升一伏。 | 鼎器屬金，成用靠水火木，設立又靠土，一器具五行，以水火為要。故鼎本離火，與本坎水的井相對；兩卦下皆巽，使水能上升、火能伏藏，一升一伏。 |
| 既濟之象。生成之功。天地尚依此升伏以成化育之用。而況人乎。故井之用。以水養民。鼎之用。以火養民。而皆賴風木以運之。化之。推而致之。光而大之。故兩卦皆巽在下。而坎離分主其上也。離與巽合。 | 形成既濟生化。天地尚靠升伏化育，何況人？井以水養民，鼎以火養民，都靠風木運化、推廣其用，故同以巽在下而坎離分居上。離與巽合時。 |
| 則為火而非日。巽與離接。則為木者多。為風者少。然火固非風不燃也。象雖木火。用兼風氣。故稱名曰火風鼎。不曰木火。為木易見。風難知也。巽于物。為風或木。于用。為順或入。此鼎卦亦包有風順于火。 | 離作火而非日，巽接離則木象較多、風象較少，但火也須風助燃。因此象以木火為主、用兼風氣，稱火風鼎而不稱木火，是提醒風的隱性作用。巽於物為風木，於用為順入，鼎也含風順於火。 |
| 木入于火之意。實則互成其用而已。順入毋多辨焉。辭以明揭其順入之義。如井之巽乎水而上水是也。木有質。火無質。在未燃前木也。既燃則為火。既燼則木火同灰。故火者木所生。亦五行生生之例也。 | 木進入火的意思，實際都是互相成用。像井說巽入水而提水。木有形、火無形；未燃是木，燃後成火，燼後同歸灰，火由木生，正是五行相生。 |
| 鼎取木之入火。而生火。以成火之用。故巽在下。明所自也。傳曰革去故也。鼎取新也。鼎以木火生化而熟物。如天之化育。萬物同新。非鼎能新之。以變其原有而易為新生之象。如天之春。變化其枯朽者。而更生之。 | 鼎取木入火、生火成用，所以巽在下，說明火的來源。傳說革去故、鼎取新；鼎用木火熟化食物，如天地化育使萬物更新。它不是憑空造新，而是改變原物，像春天使冬日枯朽重新生長。 |
| 繁榮之。以成新氣象。冬寒之後。葉脫草萎。春風一吹。花榮枝茂。前之凋敝者。忽欣欣然自盛。前之枯槁者。忽鬱鬱焉自繁。此非天地新之而何。鼎之新物。亦猶是也。就其成用。亦有從新之義。則鼎用金屬物。 | 寒冬後葉落草枯，春風一吹便花枝繁茂，原先凋枯者忽然欣欣繁盛，正是天地更新。鼎使食材更新也相似。從器物看也有從新義：鼎以金屬製成。 |
| 取其堅也。如革之名革。取其韌也。堅韌則能化變他物。而己不損。水火者。生化之主。木者初生之物。因三者之合。乃使舊者為新。不良者為良。不用者有用。此與革義相應也。不過革重在變去其故。 | 取其堅固，如革取其堅韌；堅韌才能化變他物而自身不壞。水火主生化，木是初生之物，三者合力使舊變新、不良變良、無用變有用，與革義相應；只是革重去故。 |
| 而鼎則重在變生其新。此本末始終之事也。鼎革往來。皆四陽兩陰爻卦。而革六二九五。恰乎乾坤正位。鼎則九二六五。反乾坤之正。卻同地天交泰之象。乾下于坤。則巽于柔。內陽外陰。天道下逮。如春夏之時。 | 鼎重生新，是同一事情的本末始終。鼎革互為反卦，皆四陽二陰；革六二九五得乾坤正位，鼎九二六五則相反，卻像地天泰的乾下坤上、內陽外陰，天道下交，如春夏時。 |
| 天地交道。萬物繁庶。故名鼎。鼎盛也。隆也。重也。崇高之謂也。鼎古通頂。頂。頭頂也。亦高貴尊重之意。古人以鼎烹飪。後世視為神器。亦尊崇之也。鼎字象形。而鼎鼐王和羹之責。故稱宰相調和鼎鼐。 | 天地交而萬物繁盛，所以名鼎。鼎含盛大、隆重、崇高，也與『頂』古通，有高貴尊重義。古人本用鼎烹飪，後視為神器。宰相稱調和鼎鼐，也取烹調和羹之象。 |
| 雖本書和羹之言。實亦取其在神器之側。司傅保之職。宣中和之道。贊位育之功。蓋本乾卦乾道變化。各正性命。保合太和。乃利貞者。可見鼎鼐之用。足配天地生成之德。賢聖化育之功。豈徒烹飪熟食養民已哉。 | 但更深義是宰相近神器、負輔弼責任，宣中和、贊天地位育，合乾卦各正性命、保合太和。鼎鼐作用可配天地生成與聖賢化育，不只熟食養民。 |
| 然同一養也。養其口腹。與養其身心。養其身家。與養其國天下後世。是在善推其用而已。聖王養己。必先養民。養民必先養賢。上則烹以享上帝祖先。下則烹以享侯國臣庶。皆資于鼎。是則鼎之功用。不可量也。 | 同是養，可以由口腹推到身心，由一家推到國家天下後世。聖王養己先養民，養民先養賢；上用鼎祭天祖，下用鼎宴諸侯臣民，鼎用因此不可限量。 |
| 夏禹鑄九鼎。以昭示天下。天下遂歸夏。而世傳之。湯武革命。遷鼎建國。以開基業。天下服之。皆視鼎之所在。為社稷之保。宗廟之尊。得之者。君臨四海。失之者。放逐誅夷。以鼎能養民也。民之所歸。天之所予。 | 禹鑄九鼎象徵天下歸夏；湯武革命後遷鼎建國，天下也以鼎所在象徵社稷宗廟。得鼎者君臨四海，失鼎者被放逐誅滅，根本在能否以鼎養民；民歸即天予。 |
| 故革卦以湯武革命順天應人。鼎因隨民心所移而移。偕民心之定而定。是得鼎者。得其民。失鼎者。失其民。鼎之所關豈輕易耶。蓋鼎為養民之本。民得其養。莫不來歸。民失其養。莫不攜貳。民之所視。天亦視之。 | 所以革卦說湯武順天應人，鼎也隨民心而遷、隨民心安定。得鼎就是得民，失鼎就是失民。鼎關係重大，因它象徵養民；民得養便歸附，失養便離心。民所視聽，也就是天所視聽。 |
| 民之所聽。天亦聽之。凡民之順逆。必以國之賢者為依歸。故養民者先養賢。湯武得賢且得民。桀紂失民亦失賢。故失賢者。鼎不得保存矣。重器一失。社稷同隳。賢愚皆離。宗廟不享。此鼎之動定。繫乎存亡興替。 | 人民順逆又以國中賢者為依歸，所以養民先養賢。湯武得賢得民，桀紂失賢失民；失賢便不能保鼎，重器一失，社稷宗廟同敗。鼎的動定關係國家存亡興替。 |
| 豈徒一器之得失已哉。故周易以鼎次革。其意義實深遠矣。 | 絕不只是一件器物得失，所以《周易》以鼎接在革後，意義深遠。 |

| 鼎取新。為物數之更新。與革相往來。革去故。而鼎用新。成繼續變易之象。窮則變。變則新。此天道也。如一歲由冬而春。時序迭謝。歲月以更。則舊者有續。而窮者不窮矣。鼎為器。乃人生必需之器。 | 鼎取新，象徵事物更新，與革互為往來：革去故，鼎用新，連成持續變易。窮則變、變則新，如冬去春來、歲序更替，使舊有承續、窮者不絕。鼎也是人生必需器具。 |
| 自燧人氏鑽木取火。教民熟食。始有烹飪之術。而鼎遂為人生要器。以烹飪必藉鼎也。故鼎與井。皆養生之物。實民生之本。民未有不汲于井者。亦未有不烹于鼎者。故鼎為家人主器。傳稱鼎之後為震。家之主器。 | 自燧人鑽木取火教民熟食，才有烹飪，鼎遂成要器。鼎與井都是養生根本，民要汲井，也要用鼎熟食。鼎之後接震，傳說家中主器由長子承擔。 |
| 必以長子。民生雖賴鼎以烹飪。而主持之者長男。如俗稱長房。為代父治家之人。在天道則屬東方木。而令為春。春為一歲之首。故鼎新之象。必見于震。猶萬物之生。必依于春。此鼎雖與革往來。而實與震相連繫也。 | 鼎雖供民生，主持家務者象長男，如長房代父治家。天道中震屬東方木、時令為春，春是一歲之首，所以鼎取新的象必見於震，如萬物生於春。鼎雖與革相反，也與震相連。 |
| 鼎之初。不過烹飪之用。其後則為祭祀之供。推而成社稷重器。自禹鑄九鼎。列于廟堂。于是有天下者。視若神器。宗廟所在。社稷所依。皆以鼎昭其象。故國有變。則鼎不保。興王建都。名曰定鼎。革命遷都。 | 鼎初只供烹飪，後用祭祀，再推為社稷重器。禹鑄九鼎列廟堂後，天下共主視為神器，宗廟社稷都以鼎昭示。國有變則鼎不保，興王建都稱定鼎，革命遷都稱遷鼎。 |
| 稱曰遷鼎。可見鼎之重要。又不止一家主器已也。嗣後鼎屬宗廟之器。社稷之尊。于是非神地不設鼎。非廟廷不得置鼎。非革變易君。不得問鼎之大小輕重。斯鼎為國之所有。帝王所保存。非復如前家中烹飪之器矣。 | 可見鼎不只是一家器具。後來它專屬宗廟社稷，非聖地廟廷不設，除非有改朝換代之志也不可問鼎輕重大小。鼎成國家帝王所有，不再只是家庭炊具。 |
| 主器之長子。乃變而為出帝之震。同一長男。在前不過一家之長房。今則已成天下之主。故鼎之所用。亦隨時而有異焉。然神器之鼎。本出于烹飪之制。用雖漸大。而源不可忘。是易鼎卦。仍以烹飪為先。後世烹飪。 | 主器長子也升為『帝出乎震』的天下之主：同是長男，從一家長房變成天下君主，鼎用也隨時擴大。但神器本源仍是烹飪，所以《易》鼎卦先談烹飪。後世炊具。 |
| 固由鼎代以釜鍋之屬。雖非鼎之名。仍本鼎之用。則以易卦火風合為鼎。巽與離互成其用。巽木離火。仍取義于鑽木取火之始。而納薪熟食。亦不外木火同功之意。此鼎卦大用。必以養民為先也。至于茶鼎香鼎。 | 雖由鼎改成釜鍋，名稱不同，功用仍本於鼎。火風成鼎、巽離互用，巽木離火仍追溯鑽木取火、添薪熟食，故鼎的大用首先是養民。至於茶鼎香鼎。 |
| 及一切有名鼎者。用或有殊。其本源于烹飪則一。故鼎為民生主器。亦如井不可一日無者。細讀易辭自明。 | 及其他名鼎器物用途雖異，源頭仍是烹飪，所以鼎是民生主器，如井一日不可缺，細讀易辭即可明白。 |

| 此鼎卦彖辭也。鼎上離下巽。中藏乾象。故彖辭賅乾四德之半。四德乾首元亨。坤首利貞。鼎用本離代乾。故稱元亨。而以離六二。黃離元吉。故曰元吉。亨。且兼巽之德也。鼎六五。即離六二。二五正位相匹。 | 鼎上離下巽，中互乾象，所以彖辭取乾四德前半元亨。鼎以離代乾，又因離六二辭為『黃離，元吉』，故說元吉亨，亦兼巽德。鼎六五相當於離六二，二五正位相應。 |
| 而鼎內九二。外六五。剛柔互易。本泰地天交之象。故同泰稱吉亨。合離泰之辭言。可見鼎實兼二卦之用。由離言。應稱元吉。由泰言。應稱吉亨。由乾坤交錯而首乾言。應稱元亨。合數者之德。乃曰元吉亨。 | 鼎內九二外六五，剛柔互換，如地天泰交，所以也有吉亨。合離的元吉、泰的吉亨及乾坤交錯首乾的元亨，總稱『元吉亨』。 |
| 吉字非衍文也。雖釋彖辭但稱元亨。省去吉字。非謂彖辭有誤。乃揭示鼎之大用。在合乎乾。且以文句之便。稱亨已足包吉也。以巽柔在下。上行成六五正位。乃法于坤。離柔在中。而其下反以剛居二爻為應。 | 『吉』不是衍字。彖傳只說元亨、省吉，並非原辭錯誤，而是突出鼎的大用合乾，且亨已包含吉。巽柔由下上行成六五正位，效法坤；離柔居中，下反以九二剛相應。 |
| 是本乾道也。本坤者降而升之。本乾者上而下之。因此協于交泰。同于既濟。先天乾坤。後天離坎。水火既濟。為生化之原。地天交泰。為生成之始。故鼎者。生化之所資也。以木生火。而熟物為民食。 | 這又本乾道。坤本下降而今上升，乾本在上而今下降，因而如泰交、既濟。先天乾坤、後天坎離，水火既濟是生化根源，地天交泰是生成開始；鼎正是生化所資，以木生火、熟物供民食。 |
| 因火化物而成象。以養人民。以亨神祖。其功不在天地生成之下。天地生之。不宜于養。鼎烹而熟之。方通于生。豈非鼎養之功。純本乾大生之德乎。故卦中有乾。且居下正位。如乾九二見龍在田。德施普及之象。 | 火化食物、養人民、享神祖，功用不下天地生成。天地生出的食物未必能直接養人，經鼎烹熟才可入口，所以鼎養本於乾大生之德。卦中互乾又居下正位，如乾九二見龍在田、德施普及。 |
| 德自下積。施自上成。故德施之昭。乃大人功行之基礎。而鼎效之。鼎雖一物。其用足多。上而祀天。下而生民。中養賢能。報酬功德。以成亨禮。其為用豈小哉。故德稱元吉亨。而亨字兼烹與享三義。以其通于一切。 | 德從下積，施於上成；德施昭著是大人功業根基，鼎也如此。鼎雖一器，用途廣：上祭天、下養民、中養賢、報功成禮，作用甚大，所以稱元吉亨。『亨』兼亨通、烹飪、祭享三義。 |
| 而率天下以成禮。所謂嘉會是也。以其著熟食之功。成養賢報功之典。所謂燕饗大餔。養老諸禮是也。皆有資于鼎。可見彖辭元吉亨之占。實由其用可以明之矣。 | 它通於一切、率天下成禮，成就嘉會；又以熟食養賢報功，宴饗、大餔、養老等禮都靠鼎。彖辭元吉亨，正可由其功用明白。 |
| 彖曰。鼎象也。以木巽火。烹飪也。聖人烹以享上帝。而大烹以養聖賢。巽而耳目聰明。柔進而上行。得中而應乎剛。是以元亨。 | 彖傳說：鼎取器物之象。把木順入火中，就是烹飪。聖人烹煮以祭享上帝，大烹以養聖賢。內巽順而耳目聰明；柔爻上進，得中位並與剛相應，所以元亨。 |

### 宣聖講義

| 原文 | 白話文 |
|---|---|
| 此申釋彖辭之義。而明鼎卦之用也。鼎象也。言以卦象形。巽兩陽一陰。初六如鼎足。二至四如鼎腹。六五如耳。上九如蓋。是鼎之象。而剛在中。如火在鼎內以熟物。巽順也。入也。以木巽火。即以木入火。 | 這解釋彖辭與鼎用。卦形像鼎：初六如足，二至四如腹，六五如耳，上九如蓋；中間剛爻又像鼎內有火熟物。巽是順入，以木巽火就是把木送入火中。 |
| 使之燃燒。而上有物。則非徒燒也。是為烹飪之象。蓋以木生火。非盡為烹飪者。而既象鼎。則必為烹飪无疑。故名鼎。明其用在于烹飪而已。烹飪者。熟物以食。為養生之資。物不熟不能食。食亦不能養人。 | 使木燃燒，上方又有食物，便是烹飪而非徒燒。木生火不一定都用來烹飪，但卦既象鼎，作用必是烹飪。烹飪把食物煮熟以養生；不熟難食，也難養人。 |
| 是烹飪之旨。在養民。而鼎之用。亦為養人。以人方知熟食之利。其他生物不知之。亦不能之。是所謂養生者養吾人類。然非止人之自養。必追溯所生之本。天生之。親育之。則以自養者。亦必以報其生育恩勤。 | 所以烹飪旨在養民，鼎用也在養人，因只有人類懂得熟食之利。但人不能只自養，還要追溯生命根源：天生、父母育，靠自養之力也應報答生育恩德。 |
| 而養神祖。則祭享尚矣。祭祀有尊卑之序。則非盡人能享天地者。惟聖人則烹以享上帝。聖人稱在位者。天子是也。在上位代其下民。致其祭享。故享上帝。天子之禮也。然非徒享上帝已也。 | 因此要祭養神祖。祭祀有尊卑，不是人人都能祭天；在位聖人即天子，代表下民奉獻祭享，故享上帝是天子禮。但不只祭天。 |
| 必推及人類之所仰望而利賴者。以廣其自養。養民之心。則必先養天下聖賢。聖賢非限于生民。先民有德于民。有功于世者。亦皆享之。則必大烹以昭其養。 | 還要推及人所仰望依賴者，以擴大養民之心，首先養天下聖賢。聖賢不只當世，也包括先民中有德於民、有功於世者，都以大烹祭養。 |
| 養猶享也。以敬禮言曰享。以生育言曰養。如孝親亦養也。以事存言曰養。以事亡言曰享。孝子不死其親。則事亡亦養也。故聖王因鼎之烹飪。既以享上帝。復以養聖賢。聖賢為民所尊依。聖賢得養。民亦必得養。 | 養與享相通：就敬禮說享，就生育說養；侍奉在世者稱養，侍奉亡者稱享，但孝子不把親人視為永絕，事亡也可稱養。聖王用鼎既享上帝，也養聖賢；聖賢為人民尊依，聖賢得養，人民也必得養。 |
| 蓋養民簡易。養聖賢則尊嚴。雖不及養民。實則鼎養不得外夫民也。故享字與亨同。以其通諸天下無不亨也。無不亨。則無不烹。無不享。無不養。聖人率之。天下從之。聖人啟之。天下糜之。此鼎之重亨與養。 | 養民較普遍，養聖賢更尊嚴；鼎養實際仍不能離民。享與亨同，意在通天下：無不亨、烹、享、養。聖人倡導，天下跟從，這就是鼎重亨養。 |
| 而必自天子至于庶人也。故鼎之制。始于日用。終于祭享。初為民生之具。繼為宗廟之尊。則以其用由小而大。由近而遠。由微而崇也。故鼎之為器。神器也。著于廟堂。行于威儀。止于莊嚴。而不可視為尋常之物。 | 而且從天子到庶人都適用。鼎制始於日用、終於祭享，先是民生器具，後成宗廟尊器，作用由小至大、由近至遠、由微至崇。因此鼎成廟堂神器，用於威儀莊嚴，不可當尋常物。 |
| 則以關于享祀。與養賢者大矣。以卦巽在內。離在外。故曰巽而耳目聰明。謂內巽而外聰明。則以離文明之象。光大之行。因鼎之敬天而尊賢。敦仁而重義。教孝而盡禮。既承上帝之佑。復得聖賢之輔。 | 因它關係祭享與養賢。卦內巽外離，所以說內巽順而外耳目聰明；離有文明光大之象。鼎使人敬天尊賢、敦仁重義、教孝盡禮，既承天佑又得聖賢輔助。 |
| 則書所謂明四目。達四聰者也。在上位而得民之情。養其體而不忘天地之享。萬民之養。則鼎之功業盛矣哉。柔指初六。進于六五。得全卦中正之位。而與下九二之剛相應。體夫地天交泰之道。是以占元亨。 | 就如《尚書》所說廣開視聽。居上者能通民情，養己又不忘祭天地、養萬民，鼎功盛大。柔爻由初進至六五，得全卦中正，與下九二剛相應，合地天交泰，所以占元亨。 |
| 謂其備乾生之德。而全離明之功也。 | 因它具乾的大生之德，也全離的光明之功。 |
| 象曰。木上有火。鼎。君子以正位凝命。 | 象傳說：木上有火，是鼎。君子由此端正所居之位，凝固所受天命。 |

| 此鼎卦象辭也。鼎上離火。下巽風木。成木上有火之象。以火在上。不似他處延燒燎原。則雖有能燃之木在下。而非任火之自焚。是必有範之者。故取鼎為象。言鼎則凡一切能熟物之具。如爐灶鍋鑊之類。皆包括之。 | 鼎上離火、下巽木，成木上有火。火在上卻不像野火延燒，表示下木雖可燃，仍有器物規範火勢，故象鼎。凡爐灶鍋鑊等熟食工具，都可包括在鼎義。 |
| 名異而用同。則不妨視為鼎。故以木在下。火不延燒者。名日鼎。明其火自木出。而不越于物外也。若及其上下。木在火之上。則必延燒無制。而有如野火燎原之勢。故風火家人。即取其焚燒不可嚮邇。 | 名稱雖異而作用同。木在下而火不外延，表示火從木出卻受限於器內，所以名鼎。若上下倒置、木在火上，便會無制延燒如野火；風火家人正取其焚燒難近。 |
| 喻人之情欲不可遏止。設失其正。禍不旋踵。炎炎之不滅。玉石同焚。此貴乎自戢也。戢火之道。必約其勢。戢慾之道。必約其情。鼎雖有所範。以防其延燒不已。而仍必依自戢之義。以限制其焚燎之情。 | 以比人情欲一旦失正便難遏，禍患立至、玉石俱焚，所以貴自我收斂。制火要約束火勢，制欲要約束情感；鼎雖有器形防延燒，仍須主動節制。 |
| 則在乎巽之自持。換言之。在自約束其薪。少少與之。使火在鼎中。而不焚外物。使用僅熟物。而不毀其鼎。此貴乎巽也。巽則克順其道。可以進退其行。雖入而能出。雖柔而御剛。故巽者不滯于物。恆約其情。 | 關鍵在巽的自持，也就是控制薪木，只少量添加，使火留鼎中、不燒外物，只熟食而不毀鼎。巽能順道、調節進退，入而能出、柔而御剛，不滯於物，常能節制情欲。 |
| 知止則止。知行則行。進退無專。出入以衡。故鼎以巽役火。生之而能制之。長之而能弱之。如見火之盛。則抽薪。欲火之強。則進薪。是火之得中。皆巽之所為也。故君子觀鼎而得正位凝命之道焉。正位者。 | 知道該止便止、該行便行，進退不專斷、出入有分寸。鼎以巽駕馭火，能生火也能制火；火太盛就抽薪，火太弱便添薪，使火力得中，全靠巽。因此君子觀鼎而懂得正位凝命。所謂正位。 |
| 鼎卦上下九二六五。原為乾坤交易之象。乾以九二。孚德施普及之義。坤以六五。孚黃裳元吉之義。皆正位也。君子法之。亦正其位。內則以九二昭其德。外則以六五砥其行。推之國天下。上有所保。下有所歸。 | 鼎的九二六五是乾坤交易：乾九二合德施普及，坤六五合黃裳元吉，都是正位。君子效法，內以九二明德，外以六五砥行；推到國家天下，上有所保、下有所歸。 |
| 則皆不失其位。而鼎養之道見焉。凝命者。鼎以上火下木。木以生火。火以烹煉。平時日用。則熟食之功。修道礪行。則鍛煉之用。合坎離既濟之妙。成地天交泰之功。推之于國天下。上承天命。下保民命。天與人歸。 | 人人不失其位，鼎養之道便顯。凝命則取木生火、火烹煉：日用是熟食，修道是鍛鍊；合坎離既濟與地天交泰。推到國家，上承天命、下保民命，天人歸附。 |
| 大命乃定。既緣革故順應之義。自達鼎新正凝之行。此凝正之道。為君子修己安人之本也。且正位凝命。由乾道變化。各正性命。保合太和。乃利貞來。鼎中有乾。而用合于坤。所謂各正性命者。即鼎之正位凝命也。 | 大命才安定。從革故順應進到鼎新正凝，正與凝是君子修己安人的根本。此義也來自乾道變化、各正性命、保合太和。鼎中互乾而用合坤，所謂各正性命就是正位凝命。 |
| 乾首元亨。本乎天者親上。坤首利貞。本乎地者親下。萬物莫不依乾坤以有生。則莫不秉天地以立命。生有其位。惟正則中。身有其命。惟凝以和。正也凝也。中和之德也。中庸所謂苟不至德。至道不凝焉。此凝命。 | 乾首元亨，本天者親上；坤首利貞，本地者親下。萬物依乾坤而生、秉天地立命。生命有位，正才得中；自身有命，凝才和。正凝就是中和。《中庸》說沒有至德，至道不能凝聚。 |
| 即凝道。而正位。即明德。位以德正。命以道凝。此發于乾。成于坤。生于天。歸于地。乾知大始。則位先正。坤主大終。則命自凝。坤之初六。履霜堅冰至。釋曰陰始凝也。此已明凝命之道。原秉于坤。安貞之德。 | 凝命即凝道，正位即明德；位靠德正，命靠道凝。這始於乾、成於坤，生於天、歸於地。乾知大始，所以先正位；坤作大終，所以命得凝。坤初六『陰始凝也』已指出凝命本於坤安貞。 |
| 乃有其終。終以不終。生乃長生。位正則不失其守。命凝則永貞其身。此乾坤合德。于交泰平陂往復中見之。于鼎新正位凝命中成之。古之聖王。以道成身。以德成人。故位永保。而命惟新。修己以明性。則天命不二。 | 有安貞才有善終，終而不絕，生命才長久。位正不失守，命凝永保身。乾坤合德在泰卦往復中顯，在鼎卦正位凝命中成。古聖王以道成己、以德成人，所以位能久保、命能常新；修己明性，天命便專一不二。 |
| 昭德以養民。則尊位不失。不二即凝。不失即正。此君子有國天下。長保不渝。永守不易。鼎為宗廟重器。社稷尊依。人民瞻仰。世世子孫。永保弗替。果鼎之所為哉。聖人自正自凝而已。故革命則鼎遷。失位則鼎去。 | 明德養民，尊位便不失。不二就是凝，不失就是正。君子治國天下能長保不變，鼎成宗廟社稷重器、人民瞻仰、子孫永守，難道只是鼎器本身作用嗎？根本在聖人自正自凝。所以革命則遷鼎，失位則鼎去。 |
| 鼎以革而後定。命以新而後明。位以尊而後嚴。此湯武之業。傳之數百年無改也。 | 鼎經改革後才安定，命更新後才昭明，位尊正後才莊嚴；湯武事業因此傳數百年不改。 |

| 鼎象辭正位凝命。夫子已釋其義。而此四字。實為道功要訣。自來修道者。由此悟出煉精化氣之妙諦。求長生者。皆以此為焚修最要功夫。所謂爐鼎提煉。龍虎昇降。坎離交媾。鉛汞飛伏之術。不外既濟與鼎二卦。 | 正位凝命也是傳統修道要訣，後人由此解釋煉精化氣、爐鼎提煉、龍虎升降、坎離交媾、鉛汞飛伏等術，大致不外既濟與鼎兩卦。 |
| 而既濟為用。鼎為體。則以鼎能正位凝命。集眾歸一。由妄還貞。必自立鼎以安心。煉精以凝命。清心以正性。明性以成道。此合精氣神三者為一。而返于太虛也。三者原出于一。還原之法。必依鼎之正位凝命。 | 既濟為用、鼎為體，因鼎能正位凝命、集眾歸一、返妄歸真。修持要立鼎安心、煉精凝命、清心正性、明性成道，使精氣神合一、返於太虛。三者本出於一，還原須依正位凝命。 |
| 亦即乾之各正性命。保合太和。故正位者中也。凝命者和也。中和之至。復歸于一。即太極也。故鼎在身中為太極之象。合水火之用。以煉之提之。去其渣滓。存其光華。是取新也。新以易故。則常新不敝。生以換死。 | 也就是乾的各正性命、保合太和。正位是中，凝命是和；中和至極復歸一，即太極。鼎在身中象太極，合水火鍛鍊，去渣留華，就是取新；新換舊則常新不敝，生換死。 |

| 故比予人之禮儀。嘉會宴享。從容中度。和樂有節。則全其生。育其性。發其情。昭其德。以孚于天道。此亨也。而震得之。震者動也。動則易躁。然以時動。則皆中節。所謂和也。和則為亨。以其本乾元之始而亨也。 | 比在人事就是禮儀嘉會和樂有節，使生命本性情德都得發展，合天道而亨。震為動，動易躁，但按時而動便中節；和則亨，因本乾元之始而亨。 |
| 震自下發。則其氣勃鬱。其行突兀。其起也。如物之挺生。其進也。如馬之奔至。是以有震之名。以其象雷之行也。雷電行于空中。倏忽飄疾。不可捉摸。氣為之也。故其動也。令人有虩虩之感。言畏懼之心自然應也。 | 震從下發，氣勢勃起，像植物挺生、馬匹奔至，也像雷電忽然迅疾、不可捉摸，所以令人自然生虩虩恐懼。 |
| 而虩虩兼有迅疾威猛之狀。如虎之伺隙而動。相機而攫。毫無疑猜。以其疾也。故曰震來虩虩。來字明其行之所自。若不震。不知其來。而來也。則覺其震。此人物咸隨其震。而虩虩也。以震之猛。則當有其威。 | 虩虩也形容迅猛，如虎伺機攫取，毫不遲疑，所以說震來虩虩。『來』指出動勢來源；雷未到不知，來時便覺震，人物都隨之驚動。震猛而有威。 |
| 而由震之動。卻又成其仁。是仁而勇者。仁者其德。勇者其行。以勇言。則皆生虩虩之心。以仁言。則又有笑言啞啞之態。為久蟄者思啟。被囚者思釋。震動之力。無不欣欣焉以向榮。駸駸焉以條達。 | 但震動又成就仁，兼仁與勇：勇使人恐懼，仁使人笑語安樂。久蟄者得啟、受困者得釋，萬物因震力欣欣向榮、迅速舒展。 |
| 此則笑言啞啞之象也。花開如笑如解語。物之生育亦如之。啞啞者。微卑貌。以中心悅懌。而自含笑也。則震之用。能拔幽發潜。振微立懦。使各得遂其生。樂其性。適其情。成其德也。此所以占亨之由來。 | 這就是笑言啞啞。花開如笑，萬物生育也如此；啞啞形容內心喜悅而含笑。震能發潛振微，使各遂其生、樂其性、適其情、成其德，所以亨。 |
| 但震雷之氣。因地域而有遲速。由遠近而別升沉。故震驚者。百里為度。言所聞止于百里。乃人之耳聰有限非。雷之威鳴不達。則雖見電光。而不聞其聲。目所觸者耳不至。則心知其遠。而不生虩虩之驚。 | 雷氣因地域遠近而傳播不同，故以百里為震驚範圍，主要說人的聽覺有限，不是雷威不達。遠處雖見電卻聽不到雷，知道距離遠便不會虩虩恐懼。 |
| 此所以徒喜其動。不畏其威。可見天道好生。雷霆之威不過。雨露之澤有餘。以時而來。則畏者。轉為敬。驚者。反為安。故雖震驚。不喪匕鬯。以其無所損也。震為長男。主器之人。匕鬯不夫。則保全其器。 | 只欣喜其發動而不畏威，可見天道好生、雷霆威不過度、雨露恩澤有餘。按時而來，畏轉為敬、驚轉為安，所以雖震驚也不喪匕鬯，沒有損失。震為長男、主器者，匕鬯不失就是保器。 |
| 此鼎卦之用。承受其業。以成其德。則匕鬯不傷。鼎食無害。且人生貴在有養。如萬物之于雨露。物得雨露。則生育華茂。則不喪匕鬯。亦天之德。恩威並至者也。 | 這承鼎卦之業而成德，使祭器食物無傷。人生貴養，如萬物得雨露便繁茂；不喪匕鬯也象天德恩威並至。 |

### 宗主附注

| 原文 | 白話文 |
|---|---|
| 震為四隅卦之首。乾坤六子之長。故稱長男。在時為春。一歲之初。在方為東。四方之始。五行為木。群生之長。後天以震。率領群倫。有如人間帝王。傳曰帝出乎震。此指太乙。主天地生化者。佛家謂之帝釋。 | 震為四隅卦首、乾坤六子之長，故稱長男。時為春、方為東、行為木，都是生長之首。後天震率群倫，如帝王；『帝出乎震』原文以太乙、帝釋等觀念解作天界生化之主。 |
| 即後天天界之尊。出者。言自此出行也。按九宮方位。徧歷各宮。歸還中央。而其始出必在震地。即東方也。甲乙屬木。生陽之地。陽自地生。一陽初生曰震。以其由坤三陰變為兩陰一陽。而陽始于下。陽主升。 | 『出』是由此開始運行，循九宮各方後歸中央，起點在東方震位。甲乙木是生陽之地，一陽初生為震；坤三陰變成兩陰一陽，陽始於下而主上升。 |
| 自下始動。如物之生。自根實初芽。生機之初見也。陽自地下萌動勃起。以出于地面。如天地間春日。陽氣外洩。鳴于太空。謂之雷震。故名震。言如驚蟄後之雷。轟然一聲。萬物同振。故震者振也。振作之也。 | 從下萌動，像根種初芽。春日陽氣由地下勃起，外洩於空而成雷震；驚蟄後一聲雷，萬物同振，所以震就是振作鼓動。 |
| 鼓動之也。由靜而動。由息而起。皆震也。一陽之德。越乎一切。本乾健之道。以自強而不息。不息則起。如人之眠後起也。起則不復靜矣。故震者有為也。帝由震行。歷于九宮。物由震動。茂于四時。人由震起。 | 由靜轉動、由息而起都屬震。一陽本乾健、自強不息，不息便起，如人睡醒；起後開始有為。帝由震出行九宮，物由震而四時茂，人由震起而成德業。 |
| 作其德業。數由震始。成其消息。故震在卦為後天之長。同日之出。當陽之興。主歲之春。率萬物而同生。成此在鼎新之餘。而必以震繼其道也。革故鼎新。是已變也。鼎峙震起。則又變焉。以靜不可久。 | 數也由震開始消長，所以震是後天之長，如日出陽興、春率萬物同生。鼎新完成後必以震接續：革故鼎新已有一變，鼎立震起又再變，因靜不能永久。 |
| 久則反為動也。鼎者重器。器必有主。主器者。莫若長子。故周易之序。以震繼鼎。言鼎有所歸。必歸于世之所尊。天下之主。家庭之長。皆主器者。靜以御動。則鼎自新。作以承息。則震隨起。此動靜作息。 | 久靜必轉動。鼎是重器，器必有主，主器莫若長子，故震接鼎，表示鼎歸於世所尊者；天下主與家長都主器。靜御動而鼎新，動承息而震起，動靜作息相續。 |
| 相繼而不止。周廻而無窮也。雖鼎與革往來。震與艮往來。若不相涉。實則鼎革四陽二陰。一變而成震艮二陽四陰。恰相對待。自成循環。觀其爻象。即可知之。震艮往來。實即一卦顛倒而成兩卦。震倒即艮。 | 循環無窮。鼎革互反、震艮互反看似無關，實則鼎革四陽二陰，一變成震艮二陽四陰，彼此對待循環。震倒即艮。 |
| 震陽在下。艮陽在上。以中互言。震互水山蹇。是動之難。而艮互雷水解。則止之怠。動自下上。其難可知。艮自上下。其怠易見。然震中有艮。艮中有震。則兩卦之用原相賅。可見動者宜知止。止者宜知動。 | 震陽在下，艮陽在上。震互水山蹇，表示動之難；艮互雷水解，表示止久易怠。震由下升難，艮由上降易；但震中有艮、艮中有震，兩卦作用相含，動者要知止、止者要知動。 |
| 此固盈虛相倚。利害相伏。天之道也。陽生而陰退。陽長而陰消。震以陽得時。故在下而能升。少而能勝。初起而強。此震為生化之長。春之象也。而以動為義。動則多變。吉凶悔吝。皆由動生。此震曰震慄。 | 盈虛利害相倚，是天道。陽生陰退、陽長陰消；震陽得時，雖在下、少而初起，仍能上升取勝，所以主春生化。但動多變，吉凶悔吝都由動生，震辭多言戰慄危懼。 |
| 言多危懼也。物之初生。恒自奮發。本陽氣之動也。故震有奮發之義。以其勢不可遏止。故與艮正反。在先天震與巽對。巽為入。亦與震起反。震強而巽懦。震剛而巽柔。故震為長男。陽之長。巽為長女。陰之長其。 | 萬物初生常奮發，正是陽動；勢不可遏，與艮止相反。先天震又與巽相對：巽入與震起相反，震強剛、巽弱柔，所以震長男、巽長女。 |
| 情性懸殊。則其為用大異。而象物則皆為木。以後天同方相近也。木亦有剛柔之別焉。故在天象。震為雷。巽為風。已不同矣。雷行迅疾而勃起。風行舒卷而續及。是在天已異其用。卦之象物。因爻之得時與否。 | 性情作用大異，但後天位置相近，象物都可為木，木也有剛柔。天象震為雷、巽為風：雷迅疾勃起，風舒卷延續，作用不同。 |
| 陽者上升本于下。陰者下降源于上。卦皆自初爻始。此先天之義。以其變明所自也。故震為剛初動。巽為柔初成。八宮卦相對舉。如艮與兌也。惟周易則以震艮往復。巽兌往來。是與先天之序有殊耳。 | 陽上升始於下，陰下降源於上，卦變都從初爻看來源，所以震是剛初動、巽是柔初成，先天相對如艮兌。周易後天則以震艮、巽兌互反，次序不同。 |
| 彖曰。震亨。震來虩虩。笑言啞啞。震驚百里。驚遠而懼邇也。不喪匕鬯。出可以守宗廟社稷。以為祭主也。 | 彖傳說：震亨。震來使人恐懼，後能笑語安定；震驚百里，是遠者驚、近者懼。不喪匕鬯，表示長子出而能守宗廟社稷、成為祭主。 |

### 宣聖講義

| 原文 | 白話文 |
|---|---|
| 此申釋彖辭之義也。以震彖辭。稱震亨。雖威加于眾。而恩亦至焉。物由震以蘇生。天假震以化育。此所以為亨也。震來虩虩。笑言啞啞。為全卦最要之義。即指由恐懼而生恭敬之心。以自警。因遂其生。樂其道。 | 震雖有威，恩澤也至；萬物因震甦生，天藉震化育，所以亨。虩虩與啞啞是全卦核心：先因恐懼生敬與警戒，後能遂生樂道。 |
| 而有欣榮之志。以體天和。而各厚其德也。故此二句。凡三見焉。至初爻釋文。始述其義。釋彖但本彖辭序列而已。震驚百里。亦承上二句來。震驚之義略別。震者懼。驚者動。其情有輕重。故稱百里。明有遠邇之分。 | 並有欣榮之志、體天和而厚德。這兩句全篇三見，到初爻象傳才詳釋。『震驚百里』承前，震偏懼、驚偏動，情有輕重，百里表示遠近差。 |
| 遠則驚。而動作以自振起。邇則震。而恐懼以自戒飭。故曰驚遠而懼邇也。如雷電發于雲中。遠則惟驚。近則必震。蓋聲威可畏。不似光耀之和平。而電者氣也。近則氣盛。遠則氣衰。故聞其轟烈之鳴。 | 遠則驚而振作，近則震而恐懼自戒，所以說驚遠懼邇。雷電發雲中，遠處只驚，近處必震；聲威可畏，電氣近強遠弱，聽到轟鳴便覺天威近在咫尺。 |
| 則覺天威之咫尺。雖狂夫愚婦。莫不恐懼戰慄不勝。以其近也。若但見其電。未聞其雷光華閃然。一瞥即逝。則見之者。不過忽生驚訝之念。而非畏懼莫安之情。以其遠也。故震與驚。動與懼。由百里判之。 | 連一般人都恐懼戰慄。若只見閃電未聞雷聲，光一閃即逝，只感驚訝而不至不安，因距離遠。所以震與驚、懼與動，以百里分別。 |
| 百里內者近。百里外則遠矣。且言百里。亦包有其威嚴甚壯。雖百里亦屆之意。可見天威時布。天視式昭。天心時敏。天聽式聰。聰明正直。神德至矣。人胡不驚。物胡不震。雷鳴則雨降。電發則陽宣。此仁德之施。 | 百里內近、外遠；百里也形容雷威遠達。天威時布、視聽昭明，人物怎能不驚不震？雷鳴雨降、電發陽宣，又是仁德普施。 |
| 生化之普及。必以春夏之時致之。此震之用。天道也。時宜也。而人物咸被其恩。而畏其威矣。不喪匕鬯者。言震驚之際。而中心不搖。恐懼之餘。而神志若一。則不以驟然之震。而失所持。不因茫然之時。而損其器。 | 這種生化在春夏按時發生，人物既受恩也畏威。不喪匕鬯是說震驚時內心不搖、神志專一，不因突發而失手，不因茫然而損祭器。 |
| 故比之祭祀重典。嘉會大禮。雖偶爾有所驚觸。仍不傷于祭器或食品。則可見其從容有度。莊敬自強。心存敬畏之思。志無紛歧之念。行守矩矱之節。形猶磐石之安。則驚而不昏。懼而不惑。動而不亂。震而不欹。 | 所以用祭祀大禮作比：偶受驚仍不傷器物食品，顯示從容有度、莊敬自強，心存敬畏、志不紛亂、行守法度、身穩如磐石，能驚而不昏、懼而不惑、動而不亂、震而不倒。 |
| 且愈以自莊。常有其度。非能養之有素。習之有方者。不可得也。故平日執虛如盈。視輕若重。無時不守禮。無行不循法。則可以任大而致遠。負重而行艱。謹嚴于顛沛之間。端正于造次之地。則儼然眾之主宰。 | 並因驚而更莊重。這非平日修養有素不能做到。常能執虛如盈、視輕若重，守禮循法，才可任大致遠、負重行艱，在倉促困頓中仍謹嚴端正，成為眾人主心。 |
| 神所憑依。萬目斯瞻。四海具望。此雖不君臨天下。子撫人民。亦足以代攝朝儀。主持祭典。是以不喪匕鬯。即可以守宗廟社稷。為祭主也。祭主者。君也。震本帝出之象。而非九五之尊。故曰出。言自震以出也。 | 受神所憑、天下仰望。即使尚未君臨天下，也足以代攝朝儀、主持祭典。因此不喪匕鬯表示可守宗廟社稷、作祭主。祭主是君，震有帝出之象但未在九五尊位，所以說『出』，即由震而出。 |
| 又出對守言。意謂如君之出。太子留守。君王有行。世子監國之例。故用出字。實包數義。而原文亦有脫耳。就不喪匕鬯釋之。則以震本長子。主祭最宜。既主重器之鼎。即可繼承宗廟社稷之守。是雖未履尊位。 | 出也可與守相對，如君王出行、太子留守監國。震為長子，最宜主祭；既能主鼎重器，就可承守宗廟社稷。雖未登尊位。 |
| 已有其德。未果為君。已堪其任。故曰出。言彼出則可為人主。不然。匕鬯細物。而非重器。何以能知其可守社稷。主祭祀。則以匕鬯。雖微而關于祭享之用。小微猶慎。更可見其大事不渝。且匕者具也。鬯者物也。 | 已有其德，尚未為君已堪任，所以說出。匕鬯雖小卻關祭享，小事尚慎，可知大事不變。匕是器，鬯是祭酒。 |
| 皆為烹鼎之需。鼎者重器。物具有失。則貽鼎鼐之羞。匕鬯不全。則戾烹調之義。是不喪匕鬯。正以見其能主重器矣。比之井卦。羸其瓶。失其繘。有乖井養者。正相對照。井以不堪大任。而廢其事。震以能謹小節。 | 都與鼎烹相關；失器失物便羞辱鼎鼐、違烹調祭禮。不喪匕鬯正顯能主重器。這與井卦瓶破繩失、不能成養正相反。井因不堪任而敗，震因慎小節。 |
| 而致其功。則雖非乾。而可代乾。以主宗廟社稷矣。鼎以折足而覆公餗。震以保全匕鬯而主祭事。亦自相反。惟震因恐而自慎。由動而自強。慎則有乾惕之心。強則孚行健之道。此所以稱其可守宗廟而主祭事。 | 而成功，雖非乾也能代乾主宗廟。鼎九四折足覆餗，震則保全匕鬯，亦相反。震因恐而慎、由動自強；慎有乾惕之心，強合行健之道，所以可守宗廟主祭。 |
| 傳曰主器莫如長子。即以震能繼鼎。而竟其養民之道。新民之功。故釋彖文。特明述其用甚大。非徒震驚也。而祭主享宴。恰本亨字來。亨即享。亦即烹字。乾嘉會足以合禮。亨之用也。 | 『主器莫如長子』就是震接鼎、完成養民新民。彖傳特別說明其用不只震驚。祭享宴饗又本於『亨』通享、烹，合乾嘉會成禮。 |

| 此震卦象辭也。震六爻卦上震下震。如離坎然。故在原卦兩陰一陽。合成四陰兩陽。而上下相應。初與四皆陽。二與五。三與上皆陰。則陽自下始。至四爻後。相接而起。遂如波浪。一起一落。落而後起。 | 重震上下皆震，如重離坎。原震兩陰一陽，重成四陰兩陽，上下相應：初四陽，二五與三上陰。陽由下起，到四又接續，如波浪一起一落、落後再起。 |
| 與坎卦象正同。坎下卦九二。上卦九五。兩陽相應。中介兩陰。亦如水波之前後相接。中間自落。如片段然。故坎卦象曰水洊至。而震卦象曰洊雷。原卦震為雷。雷之行于雲中。亦猶波之行于水面。雷者陽氣。 | 與坎象相似。坎九二九五兩陽相應，中隔兩陰，如水波前後相接中間低落，所以坎說水洊至，震說洊雷。雷行雲中也像波行水面；雷為陽氣。 |
| 而雲則陰。波者動浪。而水本靜。靜生動。則波成。陽出陰。則雷震。此雷之行。如水波之相接。自成推衍之勢。起落之情。故曰洊。洊又重也。再也。前已見。而後復見也。或謂之疊。一片一片。相壓而不斷也。 | 雲為陰；水本靜而動成波，陰中陽出而雷震。雷行如波相接，自然推衍起伏，所以叫洊，意為重複、再次、疊續不斷。 |
| 雷以電名。雷之發也。有光有聲。光行若龍蛇之飛逝。而聲度于空中。則以氣有強弱。雲有厚薄。道有遠近。或有崇山峻峰之隔絕。或以巨風疾雨之攪阻。則聞者若斷若續。時宏時細。遂如水波。自成低昂之象。 | 雷電有光有聲，電光如龍蛇飛逝，聲在空中受氣強弱、雲厚薄、距離山風雨阻隔，聽來斷續、忽大忽小，如波有高低抑揚。 |
| 揚抑之形。此一起一落。非果起落。而人以為起落耳。但卦象由兩陽爻。重疊接續。乃稱為洊。洊則非一度也。如雷之鳴。時相轟響。巨細不一。亦洊也。以其鳴。決非一響即止者。縱耳不聞。目猶見其光。則已遠矣。 | 實際未必真起落，只是聽者感受。卦以兩陽重疊接續稱洊，表示不只一次；雷鳴通常接連、大小不一，直到聲遠不可聞而仍可見電光。 |
| 因其重疊接續。故卦亦以上下兩震象之。此所以稱洊雷震。言震上震下。與他卦由兩不同卦合成者有殊。如離曰明兩作離。艮曰兼山艮。巽曰隨風巽。兌曰麗澤兌。皆揭示上下同卦之意。而坎之水洊至習坎。 | 所以重震象接續雷。這與其他純卦象辭相似：離說明兩作、艮說兼山、巽說隨風、兌說麗澤，都表上下同卦；坎『水洊至』尤其像震。 |
| 則尤與震類。正以雷行與水行最似也。震以洊至。則威嚴愈壯。如發爆然。連珠不絕。勢最驚人。以其聲之震也。可見天之怒威。人以雷比天之怒。謂其蓄之久。而發之驟。鬱之甚。而宣之疾。則猶人之憤怒。 | 雷行與水行相似。雷接連則威勢更壯，如爆響連珠，使人驚畏。人以雷比天怒，因它久蓄驟發、鬱極疾宣，像人憤怒發威。 |
| 而宣其威。忿恨而吐其鬱。自有可畏之情。當懼之勢。故由雷之疊鳴。君子遂有恐懼之心。而增修省之念。此人道之震。亦與天相應者也。畏威而自戒慎。知怒而自反省。君子成德之士。實以此為其道焉。有過則懼罰。 | 因此君子聽疊雷而恐懼，更加修省。畏威自戒、知怒反省，是君子成德之道。常人有過才怕罰、有罪才怕誅、行惡才內疚、妄念才氣餒；君子不同。 |
| 有罪則畏誅。行惡則有疚于心。念妄則多餒其氣。此常人之情。而君子則否。為其不待罰而自改其過。不犯誅而已逭于罪。無惡行則心自坦舒。而少內疚。少妄念則氣自充沛。而不中餒。故曰君子有終身之憂。 | 他不待罰便改過，未犯罪便避罪；無惡則心坦，少妄則氣充。所以君子有終身之憂而無一朝之患，因時時恐懼修省。 |
| 無一朝一夕之患。為其克時時恐懼修省也。恐懼者。如中庸戒慎乎其所不賭。恐懼乎其所不聞。以天之威。神之德。時自警惕。而飭其行。敬其事。止于至善。則喜怒哀樂不害于性。中和位育。永契于天。蓋本乾九三。 | 恐懼如《中庸》戒慎於不見、恐懼於不聞，常以天威神德警惕，整飭行事、止於至善，使喜怒哀樂不傷性，中和位育而合天。這本於乾九三朝乾夕惕。 |
| 朝乾夕惕之道也。修省者。克己復禮。反身而誠。即大學誠正修身之道。莫見乎隱。莫顯乎微。修身踐言。內省不疚。則無過不及。惟中惟一。以同于天道。亦本乾自強不息之教也。故因聞雷而驚畏。而悔改者。 | 修省就是克己復禮、反身而誠與誠意正心修身；隱微最顯，修身踐言、內省不疚，不過不及、惟中惟一，以合天道，也是乾自強不息。因聽雷才驚而悔改。 |
| 常人之行。因讀震卦象而恐懼。而修省者。君子之行。此則坤履霜而知堅冰之至。見幾而作。不俟終日之謂也。智周于萬物而不遺。行合于天地而無過。則不待象之著。而明其必然。不因機之熟。而預為之備。 | 只是常人；讀震象便預先恐懼修省，才是君子。如坤履霜知冰至、見幾而作，不等事情成熟。智慧周萬物、行合天地，未等現象明顯已知必然，預為準備。 |
| 故居子綽綽然有餘裕矣。夫震天道也。而人道則重在戒懼反省。不畏其已宣之威。而懷其未至之刑。不貪其已昭之澤。而育其未明之德。是以洊雷震。而先恐懼修省。人道既盡。天道不違。則順以致之。皆位育之功。 | 所以君子從容有餘。震是天道，人道重戒懼反省：不只怕已發之威，更防未至之刑；不貪已見恩澤，更培未明之德。洊雷一來先修省，人道盡便不違天道，順致位育。 |
| 大以化之。即中和之德。此則乾所謂乾道變化。各正性命。保合太和。乃利貞者也。利貞之行。即自恐懼修省始。性命之正。太和之保。亦自恐懼修省成。而必以變化徵之。為雷震者。天之變也。易之震卦。 | 推廣到化育，就是中和德，也就是乾道變化、各正性命、保合太和而利貞。利貞、正性命、保太和都從恐懼修省開始完成，並以變化驗證；雷震是天變，《易》震卦。 |
| 鼎革之變也。變則可以徵矣。常人但知其常。不察其變。故不知恐懼修省。以天也何與于人。惟欣榮于春和。而忘夫秋冬之殘酷。雖幸生于暖日。而忽于蟄藏之枯寂。皆味于震。不明變化之數。不解性命之正。 | 又是鼎革後之變。常人只知常、不察變，便不知修省，以為天與人無關；只喜春和而忘秋冬，只幸暖生而忽略蟄藏，都是不懂震、不明變化性命。 |
| 遂無以保合太和。成其利貞。斯不克以人順天。以德達道。故象辭特揭恐懼修省以為誠焉。 | 因而不能保合太和、成利貞，也不能以人順天、以德達道，所以象辭特舉恐懼修省為要。 |

| 此震初九爻辭也。初九在下。為剛爻。原乾潜龍勿用之地。而在震。則屬主爻。以震陽出于陰。初九一陽。恰所自出之位。坤初化乾。一索得男。如母初育子。其子之所秉承者。大父之氣。即乾之初。故震以初九為主。 | 初九在下，本是乾潛龍勿用之位，在震卻是主爻，因震是一陽從群陰初生，初九正是陽出處。坤初變乾、一索得男，如母初育子而承父氣，所以震以初九為主。 |
| 猶坎以九二為主也。然主爻乃卦用之始。卦德之原。而非卦位之正。正位乃在九五也。陰卦以巽為初得陰。其主位亦在初爻。故名長女。與震先天相對。在後天則震艮往來。震兌對反。此其異也。震初九既為全卦主爻。 | 如坎以九二為主。主爻是卦用之始、卦德之源，不一定是正位，正位仍在九五。陰卦巽初得陰，主也在初爻，故稱長女，先天與震相對；後天則震艮互反、震兌相對。初九既是全卦主爻。 |

| 後人遂有所疑。不知初九之辭。多一後字。乃與彖異。彖概一卦始終。故無先後之別。爻為一卦之始。故加後字。明其有先後之分也。初九之象。誠如震全卦之象。以剛動于下。初為其主。其餘二爻皆柔。合之上卦。 | 初九辭比彖多一個『後』，正是差別：彖概全卦始終，不分先後；初爻是全卦開始，所以特說後，表明次序。初九剛動於下，是震主；其餘兩爻柔，與上卦合看。 |

| 此申釋爻辭之義也。以初爻在下。地卑而時未至。原當勿用之爻。而以震志于升騰。秉陽剛之德。作飛越之思。自易干躁妄之咎。而以占吉者。實由初爻能本震驚之義。存恐惧之心。戒其躁妄。抑其剛愎。而不特免咎。 | 初爻地卑時未至，本應勿用；震卻志升騰、秉剛動，容易躁妄。之所以吉，是能因震驚存恐懼，抑制剛愎，不只免咎。 |
| 且獲吉占。所以謂之恐致福也。福禍相對。恐惧足以致福。即言驕狂足以招禍。聖賢君子。莫不謹其言。慎其行。象曰恐惧修省。明震動之際。最宜戒慎之時。設涉于躁妄。而恃其剛強。偶存驕矜。而挾其盛氣。 | 還得到吉福，所以說恐致福。恐懼致福，也反示驕狂招禍。君子謹言慎行；震動之際尤其要戒慎，若躁妄恃強、驕矜盛氣。 |
| 是將以賈禍耳。奚望于成震之大用哉。故德益昭。則心益下。力益振。則情益卑。以志于平。方免于過。乾行健。以自強不息。而必先有朝乾夕惕若厲之思。況初九在下位。而非盛時者乎。故以震動而生虩虩之心。 | 只會招禍，不能成震大用。德愈明心愈謙，力愈強情愈卑，保持平正才免過。乾自強仍須朝乾夕惕，何況初九位下時未盛？所以震動便生警懼。 |
| 因震驚而發恐惧之念。始克招致福利。不干于咎戾也。笑言啞啞。正由恐致福來。故爻辭有後字。不獨以時有先後。行亦有前後也。前進而後退。不爭先。謂之後。本其欲進之志。發于必進之時。而能自警惕以讓人。 | 由恐懼才招福免咎，後笑也由此而來。『後』不只指時間，也指行動能退讓、不爭先。雖有進志且時當進，仍能警惕讓人。 |
| 是後也。後雖非志士所許。而宜後。則後為得。震驚之際。危惧之情。戰兢自持。從容中道。庶能無過。而有法度。故其後也有威可象。有儀可法。是虛己下人。卑以自牧者。猶乾九四之躍淵。與初九之下也相應。 | 這就是後。一般志士不願落後，但該後時能後才對。震驚危懼時戰兢自持、從容合中，才能無過有法；其退後顯威儀法度，是虛己下人、謙卑自牧，如乾九四躍淵與初九居下相應。 |
| 乾之道。震所則也。故震九四稱墜泥。亦即乾躍淵之意。而初九之後。亦即乾下也之行。高者貴自下。前行貴知後。即尊者自抑。進者知退。以震艮往來。反震即艮。震起艮止。故用相應。震動易干急進之嫌。 | 震效法乾，所以震九四墜泥近於乾九四躍淵；初九之後也合乾的『下也』。高者貴自下，進者要知退。震艮互反，震起艮止，作用相應；震動容易急進。 |

| 而矍矍然如睽之視。多幻變之象。戾乎正見。不辦其真妄矣。以聲之將竭。則索索焉而震。以光之將滅。則矍矍焉而視。皆本爻象之用。明震之不復進矣。不震不進。則不利于行。故占征凶。以其戾于動起之道。 | 匆忙中偶見幻變，難辨真妄。聲將竭所以震索索，光將滅所以視矍矍，表示震不能再進；不震不進便不利行，所以征凶。 |
| 強為進取之圖。則其凶可知。物窮則變。數極則改。震起之變則為艮止。振作之改。則為休憩。此征凶悖夫時地之宜。違于天人之道耳。然始有終。本有末。強弱雖異。體用不殊。故雖窮而猶震。雖凶而仍作。 | 強求進取當然凶。物窮數極便變，震起變為艮止，振作改為休息；征凶在違時地與天人之道。不過有始有終、本末強弱雖異，體用相續，所以窮中仍有餘震。 |
| 則所震者。非其本身。而屬諸隣。此則以遠近異方。我之遠。不若鄰之近。此之窮。不若彼之續。則震固未自已。而惟于其隣受之。躬之與隣。亦猶主與賓。主之利。或即賓之害。隣之震驚。或反為躬之安和。 | 只是震不在自身而在鄰處，因遠近方位不同：對我遠、對鄰近；此處窮、彼處續。主賓利害也可能相反，鄰受震驚反使自身安。 |
| 斯則時位為之。以卦言。則六三當之。六三之無眚。亦以眚在上六也。而以震兌後天卦位言。則隣者指兌。震東兌西。震木兌金。相匹敵也。故比諸隣。又艮兌相對。震反為艮。亦取兌之用。是震之隣。即兌也。 | 這由時位決定。卦爻可指六三，六三無眚而眚落上六。從後天震兌方位看，鄰指兌：震東木、兌西金相對；艮兌又相對，而震反成艮，也可取兌為鄰。 |
| 而先天則屬巽。巽為長女。如姊娣。且同屬木。異剛柔。震主躁進。巽則順其行以進退。是亦猶隣也。因震在隣。故占無咎。而剛反近柔。男以下女。無論為巽為兌。皆有婚媾之緣。而周易主後天。仍取兌卦。 | 先天則鄰為巽，震巽像兄妹、同木異剛柔；震躁進，巽順勢進退，也像鄰。震在鄰所以自身無咎；男剛近女柔，無論巽兌都有婚媾象，而《周易》重後天兌。 |
| 故曰有言。以兌主口舌也。且自六二反接初九成艮。艮兌為匹。故曰婚媾有言。蓋如澤山咸也。 | 所以說有言，因兌主口舌。六二反接初九又成艮，艮兌相配，如澤山咸，故婚媾有言。 |
| 象曰。震索索。中未得也。雖凶無咎。畏鄰戒也。 | 象傳說：震索索，是內在未得中；雖有凶而無咎，因能畏懼鄰震、預先戒備。 |

| 此申釋爻辭之義也。以上六震之盡。氣己竭。用已窮。則中無所得。而有索索之情。索又求也。搜求曰索。以視之無見。聽之無聞。搜索其中而無得也。中字兼指中爻。以上六六三兩柔相應。柔道空虛而不實。 | 上六震盡、氣用皆窮，中無所得而索索。索也可作搜尋，視聽都無所得。『中』又指中爻，上六與六三兩柔相應，空虛不實。 |
| 故曰未得。又以上六窮極。不得中行。亦曰中未得。換言之。即未得中也。六五為得中。故無喪。上六未得中。故征凶。以易偏激。而忘戒惧也。然上六重柔。本非震之大用所重。震用在初九九四也。其他四爻皆柔。 | 故未得；上六窮極不能中行，也叫未得中。六五得中所以無喪，上六失中所以征凶，容易偏激而忘戒懼。震大用在初九、九四兩陽，其他四爻柔。 |
| 皆不足當震之用。而二五得中。尚足以成震之道。故六二喪貝復得。六五無喪。以位正而行中道也。若六三上六。則失中。柔而失中。何震之為。而上六尤甚。以其窮極也。然柔道之偏。不似剛道之過。故雖凶。 | 本不足當震用；二五因得中仍能成道，所以六二失而復得、六五無喪。六三上六失中，柔而失中更難成震，上六尤其窮極。但柔偏不像剛過那樣猛烈，所以雖凶。 |
| 而免于咎。為其鑒于隣之震恐。而自戒惧耳。隣當其震。我慎其守。隣占其凶。我免其咎。故曰畏隣戒也。畏與戒應。因畏而戒。乃不受其眚。一則因畏在隣。而自戒備。一則畏隣之累。而豫戒備。皆免咎之道。 | 仍可免咎，因看見鄰處震恐而自戒。鄰凶我守，所以說畏鄰戒；一是因震在鄰而防備，一是怕受鄰累而預防，都是免咎。 |
| 震本于陽。上六陰爻。故不直受其震。而失中行。則仍易受其累。則以洊雷如波之相及也。果知其將及。而先戒慎。防其波及。而早戒備。自無凶咎之患。故索索矍矍。為警人知戒惧也。彖所謂驚遠惧邇。遠即指隣。 | 震本陽動，上六陰不直接承震，但失中仍可能被洊雷波及。能預知將及而早戒，便無凶咎。索索矍矍正警人戒懼。彖所謂驚遠懼近，遠可指鄰。 |
| 邇即指其躬。此百里震威。感受有別。而善于戒惧者。即篤于恐惧修省之君子。故畏威不必及身。懷德不必以遠。天無私。道不偏。則有聞固自驚。有見亦自省。不得以其震未及躬而忽之也。 | 近指自身。雷威遠近感受不同，善戒者就是恐懼修省的君子。畏威不必等禍及身，懷德也不因距離遠；有聞便驚、有見便省，不可因震未及己而忽視。 |

### 艮卦艮下艮上

### 宣聖講義

| 原文 | 白話文 |
|---|---|
| 艮卦與震乃一卦顛倒而成兩卦。傳曰震起也。艮止也。即一始一終之意。言自震起始。至艮終止也。又兼有動與定。初與成。本與末。下與上之別。而俗稱日出而作。日入而息。作息亦震艮也。行道者由甲地首途。 | 艮與震是一卦顛倒：震起艮止，即始終，也含動定、初成、本末、下上。日出作、日入息也是震艮；行路者從甲地出發。 |
| 達乙地休止。首途休止。亦震艮也。皆首尾去來之地。初終往返之時。概人事天道而言者也。有始則有終。有往則有復。理數如此。德用亦然。故震動于前。艮止于後。震起于下。艮休于上。震往則艮來。震升則艮降。 | 到乙地休止，也是震艮，概括人事天道的首尾往返。有始必有終、有往必有復，所以震動在前、艮止在後，震起下、艮休上，震往艮來、震升艮降。 |
| 猶日月之代明也。朝夕之相繼也。歲時之往復也。榮枯之代謝也。有春有冬。歲序乃畢。有朝有夜。日用乃成。故艮者終也。成終者成其始。如夏正建寅。歲之始也。而由子丑至寅。亦可視為終。地之兩極。終也。 | 如日月代明、朝夜相繼、歲時往復、榮枯代謝。有春冬才成一歲，有朝夜才成一日，所以艮為終，而成終也成始。如夏曆寅月為歲始，卻是子丑循至寅的結果；地極是終。 |
| 而由南北極以往返者。亦可視為始。故曰艮成終始。又曰成言乎艮。以艮一陽由初起者震。歷中爻則坎也。至上止則為艮。三陽卦。非三陽並見。乃一陽歷三級。而著其初成。示其升降耳。升者自下。降者自上。 | 從極點返行也可視為始，所以艮成終始。震的一陽由初起，中間成坎，到上止成艮；三個陽卦不是三陽並列，而像一陽歷初中上三級，顯升降。 |
| 升極必降。降極必復升。來往亦然。直立者升降之道。平行者來往之途。故震起者。至艮則止。道若相反。德實相成。不有其止。何來自起。不有其終。何來所始。故成終者亦成始。而艮則以終明乎始者也。艮主土。 | 升極必降、降極復升，往來同理。直向為升降，橫向為往來。震起至艮止，道相反而德相成；沒有止怎有再起，沒有終怎有新始？艮以終明始，艮主土。 |
| 後天代坤。為五行之母。故艮始終。兼往返。概初成。天道人事舉不能外。以物象之。則山也。土之積也。土積而高出地面者為山。山高而氣下。為其升而有降也。山之脊曰艮。音轉為岡。岡者剛也。陽止于表也。 | 後天代坤而為五行母，所以兼始終往返。象物為山，是土積高出地面；山高而氣下，顯升中有降。山脊稱艮，音近岡，陽止於表。 |
| 俗猶有呼艮者。訛作峎。人之脊。亦艮也。陽行于背。上達于巔。以脊主之。艮之道也。故人立必賴脊。俯仰動憩。必藉脊椎之力。人思必賴。腦精神氣血。必藉腦之運用。腦之本。亦交脊下達于腎。中注于心。 | 人脊也可取艮象，陽氣沿背上達頭頂。人站立俯仰靠脊椎，思慮靠腦；原文又以腦脊腎心、督脈神氣說其上下貫通。 |
| 督脈所同。神氣所貫。為其善止。故亦能行。為其有終。故亦能始。則艮者限也。範之也。有度有節。不偏不激。故中和不二。艮者退也。返本復始之道也。至極則變。達至則回。行而先止。動以後靜。故道功本焉。 | 善止才能善行，有終才能有始。艮也有界限規範、節度不偏之義，又有退返本始：至極則變、到達則回，行先知止、動後歸靜，道功本於此。 |
| 道以返原為的。逆行為用。故貴艮止。止而後定。定而後靜。定靜而後返于所始。復其天性。故止者一切之妙諦。而必適于時。遵乎道。蓋非徒止也。止中之起。靜中之動。是純乎性。全其天者。不動以動。不行以行。 | 修道以返原為目標，故貴艮止；止而定、定而靜，才復天性。但止須合時合道，不是死止，而是止中有起、靜中有動，順性自然，以不妄動而動、不妄行而行。 |
| 無為以為。無思以慮。則艮之極則。道之至功。天地猶不能違。而況人乎。此震之次必為艮也。周易之序。後天人道所遵也。艮卦以陽在上。下覆兩陰。與震卦以一陽承兩陰者。恰相反。陽止于上。則不復升進。 | 無為而成、無思而應，是艮的極則，所以震後必艮。艮一陽在上覆兩陰，與震一陽承兩陰相反；陽止上便不能再升。 |
| 故義為止。而以中爻九三六四。合成既濟之象。故利于行。止其所而利其行。則行止皆宜。是以為人道之本。下經三十四卦。艮當二十一卦。孚三七之數。亦與人道協。人道因于地。孚于天。天道七日來復。故艮數七。 | 所以義為止。但中爻九三六四近既濟，又利於行；止其所而行得宜，是人道根本。原文並以卦序數理三七說艮合人道、天道七日來復。 |
| 人道也。而合天地人三者。成其始終。則以人備天地之德。兼剛柔之道。具位育生成之功。而賅博厚高明悠久者也。乾以大始。坤以永終。合而為艮。一陽兩陰。陽奇陰偶。匹配以成。動定終始。互底于平。 | 人道取法於地而合於天，天地人共同成就始終；人兼備天地之德與剛柔之道，也參與位育生成，具有博厚、高明、悠久之功。乾主大始、坤主永終，二者合於艮的一陽兩陰，奇偶匹配，使動定終始互相歸於平衡。 |
| 此艮雖陽在上。而其用不窮也。推之一切。善進者退。善行者止。柔而濟剛。終以為始。山之巍峨。土之突峙。升降以時。初成可紀。其對為兌。窪下以瀦水。水之與土。皆生機之始。立乎至中。俯以萬里。氣根于下。 | 所以艮陽在上而用不窮。善進者知退、善行者知止，以柔濟剛、終而為始。山高土峙、升降以時；其對兌為低澤，水土都是生機之始。山立中央、俯視萬里，氣根在下。 |
| 形著于外。中藏至柔。安貞無碍。坎險不陷。乾剛不害。合以中互。雷水為解。解蹇往來。一艱一怠。止于所止。乃持其界。不偏不倚。乃慎所戒。此無咎之道。不求于外也。坎離之用。其道光明。震艮之交。 | 形顯於外，中藏至柔，安貞而不受坎陷乾剛之害。中互雷水解，與蹇往來；止於所止、守界不偏，便是無咎，不向外妄求。坎離之用明，震艮之交。 |
| 其用成平。九三上九。相應而不親。六二六五。重柔而體乎坤。故艮者得乾而歸坤。持陽而返陰。其義則止。其利則行。高而自卑。滿而不盈。達于其極。而志夫中庸。一止以息。守貞而得中。體用兼善。是人道之宗。 | 使作用平。九三上九相應不親，六二六五重柔合坤，所以艮得乾而歸坤、持陽返陰。義在止、利在行，高而自卑、滿而不盈，至極仍志中庸；一止而息、守貞得中，體用兼善，是人道根本。 |
| 斯行藏之莫悖。而利義之攸同也。 | 因此行藏不悖，利與義也能相合。 |

### 宗主疏述

| 原文 | 白話文 |
|---|---|
| 艮為少男。乃乾氣之將盡。如人老年少孑。一陽在上。陽升至極。不得復進。故艮為止。言不能前行也。若進則反為退。故退字從艮。亦言其為止也。降者至初為極。升者至上為窮。艮陽已窮。而氣已衰。于物為老。 | 艮為少男，象乾陽將盡，如老年得幼子。一陽在上，升到極點不能再進，所以艮為止；再進反成退，『退』字從艮也取此義。降至初為極，升至上為窮；艮陽已窮、氣衰，於物象老。 |
| 而稱少男。是以得乾之氣先後別之。先者為長男。即震也。一陽在初。繼者為中男。即坎也。一陽在中。後者為少男。即艮也。一陽在上。與巽離兌之三陰卦。分長女。中女。少女者相對。皆自其所出名之。 | 但稱少男，是按取得乾氣先後：震陽在初為長男，坎陽在中為中男，艮陽在上為少男；與巽離兌的長中少女相對，皆依陰陽爻出現次序命名。 |
| 故艮之陽雖窮。而年猶稚。以出乾晚耳。三畫卦如是。合為六畫卦亦然。不過成一起一伏之象。故艮象辭。稱為兼山艮。以艮象山。重艮則為兼山。兼猶連也。重叠連接之意。夏后氏之易曰連山。即以艮為首。 | 所以艮陽雖窮，年序仍少，只因出乾最晚。重艮六畫則成一伏一起，象辭說兼山艮，即兩山重疊相連。夏易《連山》以艮為首，也取兩山相連。 |
| 明取兩山相連之義。與震之洊雷。坎之水洊至固同。即與巽之隨風。離之明兩。兌之麗澤。亦無非上下相接。前後相隨之象。而艮則如山之靜而崇高。峻而巍峨。有挺出之勢。有重鎮之形。巍然獨立。卓爾不移。 | 這正取兩山相連，與洊雷、洊水、隨風、明兩、麗澤一樣，都是上下接續、前後相隨的重卦象。不同的是，艮山安靜而崇高、峻拔巍峨，具有挺出之勢與重鎮之形，巍然獨立、卓然不移。 |
| 俯臨下土。超越諸物。以在地上者。惟山為高。風雷日月。雖高于山。非立于地。不得與之並論也。故高者山。低者澤。兩相對照。而若主賓。故艮兌先天對位。其用相反。艮以高而不危。峻而不險。特立獨行。 | 山俯臨下土，地上實物以山最高；風雷日月雖高卻不立地，不能並論。高山與低澤相對，所以艮兌先天相配、作用相反。艮高而不危、峻而不險，特立獨行。 |
| 超群邁類。故擬諸人道。謂人之德性。當如艮也。知止而止。知退而退。致于至善。歸于中和。此艮為人卦。與乾天坤地。並稱三才。而夏后氏本之以立治焉。夏重人時。商重地利。周重天道。三代之易。各異其首。 | 以人道比德性，應知止知退、止於至善、歸於中和。艮因此稱人卦，與乾天坤地成三才；原文又說三代易各有側重：夏重人時、商重地利、周重天道。 |
| 即夏首艮。商首坤。周首乾。而歲時亦如之。夏建寅。商建丑。周建子。觀其曆數。知其治功。艮本人道。則凡仿艮者。皆人事之所本。人者仁也。論語曰仁者樂山。以其德性近也。艮震往來。一卦顛倒。故震往艮來。 | 所以夏《連山》首艮、商《歸藏》首坤、周《周易》首乾，曆法又分建寅丑子。艮本仁者人道，《論語》說仁者樂山。艮震顛倒互反，所以震往艮來。 |
| 行有異方。事有異宜。而震中互蹇。艮則互解。蹇解亦往來卦。以中爻言。蹇六三九四。與未濟同。艮則九三六四。與既濟類。既未濟亦往來卦也。故艮震之用恰相反。如行者背道而馳。傳稱震起也。艮止也。 | 行向事宜不同。震中互蹇，艮中互解；蹇解互反，蹇中爻六三九四近未濟，艮九三六四近既濟，既未濟也互反，所以震艮作用相反，如背道而行：震起艮止。 |
| 一起一止。亦相違。即一動一靜。一作一息之意。物極則反。道窮則變。震動之後。必屬艮止。故序卦傳曰。物不可以終動。止之。故受之以艮。言兩者相調劑也。以道言為反背。以用言為調劑。此震艮之異。 | 一動一靜、一作一息。物極道窮便反變，震動後必艮止，所以序卦說物不可終動，以艮止之。就方向看互反，就功用看相互調劑。 |
| 當于中爻證之。行者必止。進者必退。為防其窮。則必變而反其道。推之如剝與復。亦本此理。地雷復者。震之道也。山地剝者。艮之道也。消者以息。盈者以虛。陽共陰相推。剛與柔相盪。此天地生化之妙。 | 可由中爻證明。行必有止、進必有退，為免窮就要反變。剝復也同理：地雷復近震道，山地剝近艮道；消長盈虛、陰陽剛柔相推，天地生化妙用。 |
| 即在震艮往來中見之。震者振作之義。其行易躁。艮者休息之義。其志易怠。欲孚于道。必去其弊。欲成于用。必戒其過。此山雷頤為養正。而雷山小過反為過失也。蓋頤陽表陰裏。而小過剛中柔外。一順天行。 | 就在震艮往來。震振作易躁，艮休息易怠，合道須去弊戒過。山雷頤能養正，雷山小過反成過失；頤陽外陰內，小過剛內柔外，一順天行。 |
| 一違物理。各有殊也。故艮字義取山岡之挺拔。而不失其靜守之道。俗有呼山脊曰艮。者訛作峎。岡音之轉。象本卦一陽在上。覆兩陰也。陽昂于外。而陰伏于中。此德用克諧。偶以待奇。靜以御動。此道功所本。 | 一違物理。艮字取山岡挺拔而靜守；一陽在上覆兩陰，陽顯外、陰伏中，德用和諧，以靜御動，是道功根本。 |
| 故大學稱知止。佛教明止觀。止乃天下大本。一切動作。皆自止出。大哉止乎。不止將何所行。道以靜坐為本。先求止而已。故不獨人道重艮。仙佛亦自艮成。學者習艮卦。當先明此義耳。 | 所以《大學》講知止，佛教講止觀；一切動作從止出，不止便無從行。修道以靜坐求止為本，不只人道重艮，仙佛修持也重此義。 |
| 艮其背。不猶其身。行其庭。不見其人。無咎。 | 止住他的背，不再意識到自身；走過庭院，也不見其中的人，沒有咎害。 |

### 宣聖講義

| 原文 | 白話文 |
|---|---|
| 此艮彖辭也。艮卦以陽止于表。剛章于外。如人之背脊。故曰艮其背。背。與面相反。見其面者。不見其背。今艮其背。自不得見其身。身以向我言。向背猶表裏也。如人之行向前者。在後不得見其人。 | 艮陽止於外、剛顯於表，像背脊，所以說艮其背。面背相反，見背便不見正身；人向前走，後方只能看背影。 |
| 但見其背影而已。故背字對向言。兼有背馳之意。又悖也。相違也。人行固有向背。立時亦然。此背字賅立行言。惟見其背。而不相向。是以不得其身。不獲即不得。不得見其人耳。與下不見其人一義。而以背言。 | 背也含背馳、相違。人無論行立都有向背；只見背而不相向，就不能辨其身。『不獲其身』與下文不見其人義相通。 |
| 故稱身艮者止也。止于背者。即限于所止之地。止則不復動轉。故以背止者。不獲其身。如背我而立。不能見其人也。雖見之。亦不知其為誰。以不見其面目。無以辨其人也。而艮之象。一陽在上。如山之脊。人之背。 | 艮是止，止於背便限在止處，不再轉動；像背對我站立，見不到面便不知是誰。艮一陽在上也像山脊人背。 |
| 背脊之外無物也。背脊之內。則不得知。為其蔽也。艮止也。而兼限義。限于其背。則背外無可得。則所知者。惟背而已。以卦與震顛倒。震為進。艮為退。震為前。艮為後。故見震者得其前身。見艮者止其後背。 | 背外無物，背內被遮。艮兼限制，所知只到背。它與震顛倒：震進、艮退，震前、艮後；見震得前身，見艮只得後背。 |
| 正相反也。如登山者。見山之脊。不見其山之面。若不登山。則見之矣。而艮者。止而不移。故不動轉。止于上者。何以窺其側面哉。此明示艮止之道。不務旁觀。不求多識。不期移轉。不志前行。此所以為止。 | 如登山到山脊反看不到山的正面；艮止不移，不轉身旁觀。這表明止道不務多觀多識、不求轉移前行。 |
| 止于所止。永不改也。而知有限焉。行有界焉。思有位焉。見聞有所域焉。不隨物以循環。不遂事以周旋。不因人以窮達。不緣數以得失。此艮者有限者也。限于其地。限于其時。縱可得者背。而全身不可得也。 | 止於所止，知行思聞都有界限，不隨物事人數周旋得失。艮就是限於時地，縱看得到背，也得不到全身。 |
| 可言者後。而其面目不可言也。故艮止。一切動作云為皆止。雖有智者。不可易也。故有目無覩。有耳無聞。有口無言。有知無覺。則艮之境。靜定之至。無所有也。無所得也。無知亦無得也。故有行若無行。 | 只能說後面而不能辨面目。艮止時一切動作言行皆止，智力也不能改變；像有目不視、有耳不聞、有口不言、有知不覺，靜定到無所有、無所得，行如不行。 |
| 有人若無人。為耳目不用。聰明不施。神識不動。一無所觸。則心亦止。物之示我者背。我之示人亦背。背外更無可見。則雖行其庭。中不見其人。然人之見否。在我之耳目神識。覺察與否定之。庭中固未必無人。 | 有人如無人，因耳目神識不用、心也止。物對我只呈背，我對人也呈背，背外無可見，所以走庭院也不見人。但庭中未必真無人，關鍵在行者不覺察。 |
| 而行者不之見也。以心已止。則物不干。聰明已塞。則聞見不復達于外。此藏精去智。存神知化者也。故雖不見而無咎也。推之于道。止于一者。不知其餘。化于虛者。不辨其有。有自無出。果心已無。更何有哉。 | 心止則物不干，聰明內藏、不向外攀緣。止於一便不知其餘，化於虛便不辨其有；心若無執，還有何有？ |
| 眾自一分。果志已一。更何分哉。故一止天下同止。利害皆泯。得失皆刪。陰夷皆平。禍福皆淨。則更何咎哉。故艮彖辭。道之至也。推之人事。亦將如之。人事之艮。當退休之時。潛藏之際。亦以艮背為用。 | 萬殊由一分，志若專一便無分別。一止而利害得失禍福皆平淨，還有何咎？人事遇退休潛藏時也應用艮背。 |
| 所謂神龍見首不見尾者。即不獲其身之謂。蓋以艮一陽止于表。不復前進。剛昭于外。利用退藏。則有其功名者。必急流勇退。著其聲譽者。必知止不殆。此正所以保全其身。無害于人。塞其聰明。清其心志。 | 如神龍見首不見尾、不獲其身。功名已成者宜急流勇退、知止不殆，才能保身無害，收斂聰明、清心志，不為世所咎。 |
| 則人莫之見。亦不為世咎也。以卦爻言。中互解。有懈怠之勢。中藏坎。有險陷之虞。故德業不可復加。行藏必有其度。此艮其背。猶山之已崇高。尚何求于騰越哉。巍峨之極。留為萬方所瞻。峻拔之餘。 | 卦中互解有懈怠勢，又藏坎險，所以德業不可無限增加，行藏須有度。艮背如山已極高，無須再騰越；巍峨供萬方瞻仰。 |
| 將以培育其下。此山之氣反下達也。故善進者先思退。善飛者先求息。以天道不可過也。此艮之用。人道所循。行以期止。則止為道。止以備行。則行不諐。故崇高者志于卑。升進者志于退。勤作者志于息。 | 山高後反把氣下達、培育下方。善進先思退、善飛先求息，天道不可過。行為求最後知止，止又為下次行作準備；故高者志卑、進者志退、勤者志息。 |
| 功成名立者。志于休養。皆以中多險陷。人易懈怠也。見聞之極。反為不見不聞。榮顯之餘。轉成無榮無顯。非故為之。數有必至。非強致之。理有固然。艮承震動之後。不得不思其止矣。故無咎者。不止則有咎。 | 功成名立者志休養。中間多險，人又易怠，見聞榮顯到極反成不見不聞、無榮無顯，不是故意強求，而是理數必然。艮承震動後不得不止；無咎正在知止，不止便有咎。 |
| 知止則免耳。兩陽介四陰中。柔乃勝之。以陰在下也。陰本于坤。安貞之德。行地無疆。非由其善靜乎。靜以為動。則動亦靜。止以為行。則行亦止。困卦曰。入于其宮。不見其妻。與此行于其庭。不見其人。 | 知止便免。兩陽在四陰中，柔勢取勝；陰本坤安貞、行地無疆，正因善靜。以靜為動則動中有靜，以止為行則行中有止。困卦『入於其宮，不見其妻』與艮『行其庭，不見其人』相似。 |
| 皆由坎用之應。困以坎在下。而艮則中藏坎。宮者。妻所居。而不見。庭者。人所在。亦不見。豈非當見而無見乎。當見而無見。是時位為之。非人力所強。故由道言。謂之蹇兌。由人言。謂之反常。塞兌者。 | 都與坎用相關：困下坎，艮中藏坎。宮本應見妻、庭本應見人，卻都不見，是時位造成，非人力強求。從道說是閉塞感官，從人事看像反常。 |
| 內靜之功。反常者。天數之變。內靜者。去其妄。存其真。天變者。應于時。制其義。故曰艮限也。如節度也。適其節度。而不鶩于外。守其界限。而毋求于他。則艮之道盡矣。艮之為德。仁者之事。仁者靜而樂山。 | 內靜能去妄存真，天變則應時制宜。艮就是限度節度；合乎尺度、不向外馳求，守界限、不求他物，便盡艮道。艮德近仁，仁者靜而樂山。 |
| 依艮以成名。故與震相反相成。成其生化也。天道生化。皆有其時。不逾其限。寒暑有度。榮枯有數。不相失也。不相過也。故極于一。致于中。易言之。皆止也。止則永用其極。恆持其中。中極者艮也。 | 艮與震相反相成而成生化。天道生化皆有時限，寒暑榮枯不失不過；歸極於一、達到中道，都是止。止才能長保其極與中，所以艮象中極。 |
| 萬物莫不有其中極。則莫不終始于艮。如行路然。果無所止。將何以行。行行止止。斯利于用。陽剛在外。有其威儀。陰柔在內。有其涵養。定以御動。後以待先。故不獲其身。身不損也。不見其人。人無恙也。 | 萬物都有中極，也都終始於艮。如行路沒有終點便無從行，行止相間才有用。陽剛在外成威儀，陰柔在內成涵養，定御動、後待先；不獲其身不是身損，不見其人也不是人有傷。 |
| 茫茫無際。而中有不移。歷歷如波。而內無所動。故艮者道之本。德之綱。天之所以神。人之所以善。雖萬物萬事。不戾其用也。大哉艮乎。大學首謂止于至善者乎。 | 外境茫茫變動，內中仍不移不動，所以艮是道本德綱，天由此神、人由此善，萬事萬物都不違其用。《大學》所說止於至善正是此義。 |
| 彖曰。艮止也。時止則止。時行則行。動靜不失其時。其道光明。艮其背。止其所也。上下敵應。不相與也。是以不獲其身。行其庭。不見其人。無咎也。 | 彖傳說：艮就是止。該止便止，該行便行，動靜不失時，其道光明。艮其背是止在應止之所；上下爻敵應、不相交與，所以不獲其身，行庭不見人，無咎。 |

### 宣聖講義

| 原文 | 白話文 |
|---|---|
| 此申釋彖辭之義。明艮卦之用。人道之所本也。以彖辭僅指其象。示其所限。及所成用。明德達道之旨。而關吉凶者。祇無咎二字。亦不及乾坤四德。孰多孰寡。人多疑之。以為艮為人道。人道法于天地。 | 彖傳說明艮用與人道根本。彖辭只示象、界限與明德達道，吉凶只說無咎，也不列乾坤四德，容易使人疑惑：艮既象人道、法天地。 |
| 何以元亨利貞四德。艮無一焉。而首稱艮其背。末稱無咎。似艮之道。止于此而已。不知艮之為義。在于善止。一切德用。均自止成。故首曰艮其背。明所止之處也。末曰無咎。明已止之功也。不及吉凶者。 | 為何沒有元亨利貞，只說艮背無咎？其實艮義在善止，一切德用由止成。開頭指所止，結尾說止成之功；不談吉凶。 |
| 吉凶悔吝生乎動。既止則不動。不動奚有吉凶。不明言乾坤四德者。四德皆自乾元出。而非返于乾元之先者所能顯。艮止以為返本復始之道。故無復後天生成之用。則無所昭其四德焉。乾坤四德。皆溯本至末。 | 因吉凶悔吝生於動，既止不動便無吉凶。四德從乾元發於後天，艮則返本復始、歸乾元之前，不再顯後天生成四德。 |
| 自初至終。後天之所見也。在人謂之仁禮義信。仁禮義信。德之所名。而原于道。存于性。艮止以循道歸性為旨。則不復及性道所生之德也。故艮止者。一止皆止。既無動作。自無吉凶。志在先天。自不重後天四德。 | 乾坤四德自始至終，在人名仁禮義信；德名源於道、存於性。艮旨在循道歸性，便不再談由性道發出的德。一止皆止，無動作便無吉凶，志先天便不重後天四德。 |
| 此彖辭不及指出也。觀震彖辭首稱震亨。即可見震與艮之異。震者自出者也。故曰帝出乎震。艮者自成者也。故曰成言乎艮。成者誠也。誠者一也。極也。返本復始。歸于太極。太極而無極也。蓋自上而下。 | 震彖先說震亨，可見差別。震是由內而出，故帝出乎震；艮是完成，故成言乎艮。成也通誠與一，返本復始、歸太極無極。從上而下。 |
| 由一而眾者震也。自下而上。由眾而一者艮也。艮握其機。而無思無為。以達于上天之載。無聲無臭。得乾之一陽在上。而不復動。動則順夫乾元用九之道。上天之則。與震之一陽在初。秉乾初九潛龍之用。 | 由一生眾是震；自下而上、由眾歸一是艮。艮無思無為而達上天無聲無臭，乾陽在上不再動；若動也依乾元用九。震乾陽在初，則用潛龍。 |
| 主萬有之始。為天道大生。乾道知始之則者。恰相對反。震為起始。則為德用者自眾。艮為成終。則為德用者難明。一則形而下。一則形而上也。故艮彖辭先明所止。次明其虛。虛無之道。不聞不見。故有行可也。 | 主萬有起始、大生知始，正好相反。震為起始，德用眾多可見；艮為成終，德用深隱難明，一形而下、一形而上。所以艮彖先說所止，再說虛無不聞見；可以有行。 |
| 有見不可也。有止可也。有得不可也。此艮其背。不獲其身。而行其庭。不見其人。不得其身。無我也。不見其人。無人與物也。人我同無。物我同淨。則更何咎哉。故無咎。非免也。直無之。無之者。虛之也。 | 卻不可執著所見；可以止，卻不可求有所得。不獲其身是無我，不見其人是無人無物；人我物我俱淨，便無咎。不是逃過咎，而是咎本無，因一切虛空。 |
| 空一切也。道曰虛無。佛曰空。儒曰止。皆此義也。釋彖曰艮止也。時止則止。時行則行。動靜不失其時。其道光明。此數語。即申釋艮之大用。而由艮止之義。推出止與行。靜與動之相連。更以一時字。一道字。 | 道家稱虛無、佛家稱空、儒家稱止，義相通。彖傳『時止則止，時行則行，動靜不失其時，其道光明』，從止推到行、靜推到動，又以時與道統攝。 |
| 明其為止為行。為靜為動。舉不能外此。即示人道之本。體用之間。有不可分離者存。艮固以止靜為本。然其用。卻非止靜所能限也。有止則有行。有靜則有動。行止動靜。互相連繫。互成因果。且亦由比例而見。 | 止行靜動都不能外於時道，顯示人道體用不可分。艮以止靜為本，用卻不被止靜限制：有止便有行，有靜便有動，彼此相連成因果，也在對比中顯名。 |
| 形容以顯。則後天事物。不得離陰陽配合。不得以孤獨成名。此所謂對待必需之則。如行與止對待。動與靜對待。果有其一。必有其二。若無其二。不得稱名。猶人與己。物與我。來與往。進與退是也。不有人。 | 後天事物靠陰陽相對，不能孤立成名。行止、動靜、人己、物我、往來、進退都相對；只有一方，另一方也無從命名。沒有他人。 |
| 何以名己。不有物。何以名我。不有往。何謂之來。不有進。何謂之退。故止者對行言。靜者對動言。易言之。即無行自無止。無動自無靜。如人永止永靜。而終不行動者。此先天也。後天則否。故止者不行也。 | 何以稱自己？沒有物何以稱我？沒有往何來、沒有進何退？所以止對行、靜對動；若永遠先天靜止，根本無所謂止靜，後天則不同。 |
| 靜者不動也。因其行已。故名不行為止。因其動已。故稱不動為靜。蓋其用原相及也。如令之止。必前之已行。此之靜。必彼之已動。而人動以生者。事業行以成者。果無行動。即無人物事業可言。此有止必有行。 | 停止是因先前已行，安靜是因先前已動。人因動而生、事業因行而成，無行動便無人物事業，所以有止必有行。 |
| 有靜必有動。且不得或相違也。艮震往來。震者行動為用。艮者止靜為旨。則艮由震出。而反艮者。亦必歸于震。是止者終必行。靜者終必動。為後天以循環往復。盈虛消息。永相繼承。而不停歇也。然既繼承不歇。 | 有靜必有動，不能相違。震艮互反，震主行動、艮主止靜；艮由震出，反艮又歸震，所以止終必行、靜終必動，後天循環往復不歇。 |
| 則究以何而止。以何而行。由孰以動。由孰以靜哉。斯則有主之者在。即時也。道也。道立其體。時明其用。非時則不宜。悖道則不利。宜與利者。事業所由成。化育所由見。雖天地不違。而況人乎。故止者時也。 | 那麼何時止行動靜？主宰是時與道：道立體，時顯用。不合時不宜，違道不利；事業化育都由宜利而成，天地尚不違，何況人。 |
| 行者亦時。靜者道也。動者亦道。道與時不二也。言時賅道。言道賅時。為天道必以時行。人道亦以時立。故曰時止時行。動靜不失時。其道光明。光明者。正大之象。成功之期。無不宜也。無不利也。如日月中天。 | 止行都由時，動靜都合道；時道不二，天道人道都以時行立。所以時止時行、動靜不失時，便道光明。光明表示正大成功、無不宜利，如日月中天。 |
| 德用不可量也。以艮之止。非故止之。則其行也。亦非強為。艮之靜也。非智靜之。則其動也。亦非力使。此所以歸于時與道耳。時不失。道自孚焉。有不光明者哉。光明與暗昧反。中道而行。隨時而作。 | 其德用不可量。艮止不是故意強止，行也不是勉強；靜不是智力壓制，動也不是力量逼成，一切歸於時道。不失時便合道，自然光明。按中道隨時而作。 |
| 則更何暗昧之嫌。此光明者。易道所重。人道所本。由卦爻言。中藏坎而上有一陽應之。轉成離之大象。離為光明。坎之對也。故依時道者光明。悖時與道。則反暗昧。以不能坦示其中。而險陷其內。則坎之誤。 | 何來暗昧？光明是易道人道所重。卦中藏坎，上陽相應又可成離大象；離明與坎暗相對。合時道便明，違之便陷險而暗。 |
| 不得離之照耀也。艮既善止。則決不陷于險。故蹇卦以反于艮。則蹇難可除。而爻辭分往來以喻之。謂往者循坎之險。而來者。用艮之止也。故艮之用。止固不失時。行亦如之。靜固不違道。動亦如之。 | 坎陷便得不到離照。艮善止，決不陷險；蹇反於艮時難可除，爻辭以往來表示：往循坎險，來用艮止。所以艮止行靜動都不失時道。 |
| 為克知止而能靜。乃能成其行。致于動。亦如蹇之來較往宜也。艮其背者。以艮為止。而知止為始。止得其所為終。止其背。猶止于至善。方得其成。故曰止其所。言艮非徒止也。必得其地。得其時。猶黃鳥止于丘隅。 | 因能知止靜，才成行動，如蹇卦來比往宜。艮其背以知止為始、止得其所為終，像止於至善才算完成，所以說止其所。艮不是隨便停止，須得時地，如黃鳥止丘隅。 |
| 得其地也。雌雉止于山梁。得其時也。時地一也。舉地賅時。故止其所。即得其時。而上卦以陽在上。不能再升。則不得不止。是即止得其所之義。亦即艮其背之旨。陽動而自止于上。豈非宜于時。孚于道乎。 | 是得地，雉止山梁是得時；時地相通。上陽已到極，不能再升而自然止，正是止得其所、艮其背，也就是合時合道。 |
| 如日月昭于天中。萬方皆被其明。若潛于地下。是止非其所。則不得光明之稱。故明入地中為明夷。而明出地上為晉。明夷為傷。晉則進也。即風地觀。兩陽在上。亦光明下照之象。若分而合之。即兩艮相錯也。 | 如日月在天中照萬方；若潛地下便止非其所，不能稱光明。明入地中為明夷，明出地上為晉；風地觀兩陽在上也有光明下照，拆合可見兩艮相錯。 |
| 艮之陽高而視下。故得光明之稱。而為止其所之象。惟以下包兩陰。柔在剛內。全卦均不相匹應。故曰不相與。言不相協濟。如人之不相得耳。初與四。二與五。皆柔。惟三與上為剛。剛柔相背。即艮其背之辭所由來。 | 艮陽居高下視，所以光明、止所。但下包兩陰、柔在剛內，全卦上下同類相應而不相交，所以說不相與。初四、二五皆柔，三上皆剛，彼此背向，正是艮背由來。 |
| 謂艮以求止靜。故不志于合同。如人苦修。不復戀親戚之樂。家庭之情。悠然長往。與世無洽。則終成其道。永樂其淨。亦時止也。以一陽既自初至上。閱世已多。反省自易。清高之念。不移于富貴之情。光明之心。 | 艮求止靜，不志合群，如修行者淡親情世樂、超然離世以成清淨，也屬時止。一陽從初行至上，閱歷後易反省，清高不移於富貴，光明不蔽於尊榮。 |
| 不蔽于尊榮之欲。是艮之成終也。而胸中豁達。無所留滯。耳目虛空。無所見聞。此彖辭稱其不獲其身。不見其人。無咎。釋文更申言之。使讀者知艮止以清靜為重也。物欲不起。神志永一。即止也。止于至善。 | 這是艮成終：胸中豁達無滯，耳目虛空無攀緣，所以不獲身、不見人而無咎。傳文再說清靜為重；物欲不起、神志專一就是止，止於至善。 |
| 必由此致之。故在卦爻。為不相應。在人物為不相與。而在道。為獨全其天。在時。為善超于物。此中精義。非諳于修持者。難驟明也。 | 須由此達到。卦爻是不相應，人事是不相與，道上是獨全天性，時上是超然於物。此義非有修持經驗者不易立刻明白。 |

| 艮卦釋彖辭中。艮其止。止其所也。係艮其背之訛。以彖辭稱艮其背。釋文明指為止其所。即言止其背者。得其所止之地也。後人誤背作止。與彖辭不合。夫子命改正之。 | 有版本彖傳作『艮其止，止其所也』，本注認為『止』是『背』的訛字；因彖辭本說艮其背，傳文才解為止其所，應改正。 |

### 宣聖講義

| 原文 | 白話文 |
|---|---|
| 此艮卦象辭也。兼山者。就六畫卦言。艮為山。上下重艮。故為兼山。兼猶連也。合併也。叠也。兩山重叠接連不斷之狀。曰兼山。亦與兌稱麗澤。震稱洊雷同意。皆指原卦既重之象。若徒原卦。不得稱洊或兼。 | 六畫重艮上下皆山，所以稱兼山；兼是連合重疊。這與麗澤、洊雷同為重卦象，單一三畫卦不能稱兼或洊。 |
| 而兼與洊。亦頗有別。洊者前後相繼。如水之波。以其動也。兼者東西相望。如城之連。以其靜也。有如人之並立。物之同峙。雖若分立。而實相銜接。雖若獨崇。而實成起伏。故曰兼。以一卦而兼兩山也。 | 兼與洊略有別：洊像水波前後相繼，偏動；兼像山城東西相望，偏靜。如人並立、物同峙，分立而銜接、獨高又成起伏，所以一卦兼兩山。 |
| 古亦謂之連山。兼連同義。連則指其不斷。兼則示其更續。一斷一續。而仍連接。一內一外。而仍合併。故名兼山。以上下相合為重艮。故曰兼山艮。上下即內外也。遠近也。由卦爻言為上下。由物象言為內外。 | 古也稱連山。連表不斷，兼表接續；一斷一續仍相連，一內一外仍合併，所以重艮稱兼山。上下也可說內外遠近。 |
| 由事理言為遠近。因觀山者立于一面。自近至遠。視其起伏。自有異也。山靜而不動。艮止而不行。人道則之。亦以止于其所。勿志于外。故曰君子以思不出其位。位者所止之地。亦即所守之分。如立者足所履。 | 觀山由近到遠可見起伏差異。山靜不動、艮止不行，人道效法便止於所、不志外求，所以君子思不出位。位是止處、所守本分，如站立所履。 |
| 臥者身所安。皆位也。推之一切。無不有其位。位以限制其所為。範圍其所作。而艮者止也。不以作為為先。則所限者。所範者。自思起。行之先必思。思存于心。行見于事。思且不出其位。何況行乎。故言思。 | 臥時所安，都是位；萬物皆有其位以限制範圍。艮不先作為，限制就從思想開始；行前必思，思在心、行見事，思想尚不越位，行為更不會越。 |
| 即足概一切言行也。又思者欲也。願望也。中庸曰。君子素其位而行。不願乎其外。正與此辭同義。以人道法艮。必先知止。既知止。必知所止之位。此所以不復思于外也。思不出位。包一切德用言。位在卦為爻。 | 所以說思足以概言行。思也指欲望願望；《中庸》說素位而行、不願乎外，正同義。效法艮先知止，再知所止之位，便不思外。位在卦是爻。 |
| 在事物為用。在人為德位兼時也。而其行則功用也。其成則德也。故大學止于至善。先求所止。如為人君。止于仁。為人臣。止于敬。為人子。止于孝。為人父。止于慈。與國人交。止于信。仁敬孝慈信者德也。 | 在事物是用途，在人兼德位時勢；行是功用，成是德。《大學》止於至善，要先明所止：君止於仁、臣敬、子孝、父慈、交友信，這些德目。 |
| 亦即所止之位。所行之功。非僅以守為限。守即有行。故在此曰位。在一切亦曰分。分即位也。止位即守分也。各守其分。則皆成其德。天下無有亂者已。守分不失。即守正不阿。正從一止。止于一謂之正。各有其分。 | 就是所止位與所行功，不只消極守成，守中也有行。位就是分，止位即守分；人人守分成德，天下便不亂。守分不失就是守正；正可解為止於一。 |
| 則皆止于其位。更何悖謬之行哉。故艮曰艮其背。背猶悖也。不順于正為悖。或謂之逆。順受其正。即聽命于天。天命為性。止于一者。歸于性。故守分不失者。正命不違。君子居易以俟命。即止于一。以守其分。 | 各有本分就止於其位，不會悖謬。艮其背也可借『悖』義，違正為悖。順受正道就是聽天命；天命成性，止於一便歸性。君子居易俟命，正是守分。 |
| 亦即思不出其位也。正位者。天之命。本分者。人之命。持正不逆。則永正其位。安分不二。則長得其所。故善止者止于德。止于德。即止于位。亦即守其分。傳曰何以守位。曰人。人者仁也。人道配天地。 | 也就是思不出位。正位是天命，本分是人命；持正不逆可保位，安分不二可得所。善止者止於德，也就是位與分。傳說守位在仁，人道配天地。 |
| 仁德冠諸行。故人以守位。即成德以止至善。所謂成性也。立誠也。致一也。用中也。皆止也。皆止于其位也。聖人之大寶曰位。此位即分。即命也。性也。豈徒尊崇安富之為位哉。艮止而以不出位為先。 | 仁冠眾行，人以仁守位、成德止善，也就是成性立誠、致一用中。聖人大寶曰位，此位即分命性，不只是尊崇富貴。艮止以不出位為先。 |
| 足見君子之重所止。在明其性。立其命。成其德。達其道而已。簡言之。即守其分。乾坤四德。守分為貞。貞者人道之本。或謂之節。或謂之操。皆貞也。正也。一也。守節不移。守貞不失。人道斯固。而後可推為利。 | 可見君子重點在明性立命、成德達道，簡言就是守分。乾坤四德中守分為貞，也叫節操，都是正一不移。貞固後才可推成利。 |
| 廣為元亨。利者。用之著。元亨者。道之達。而貞正者。德之始。分之所由明。位之所由保也。故易卦言位必賅德。德與位不離。離則失其正。失其正。即失其守。斯悖矣。故艮其背。猶曰杜其悖。艮止即杜塞也。 | 再廣為元亨。利是作用顯，元亨是道通達，貞正是德始，也是本分明、位置保的根據。所以《易》說位也含德，德位分離就失正失守而成悖。艮背也可理解為堵住悖行。 |
| 不進則止。不通則塞。杜塞其悖逆。則所行無不順以正。在道為止于背。不以向人。在德為杜其悖。而順于正。此義似二。實一貫也。故象辭申之。以思不出位。思而出位。即不克杜其悖。而將徇其欲。以成其惡。 | 艮止本有堵塞義；阻止悖逆，行為便順正。道上止背不向外，德上杜悖歸正，兩義一貫。所以象辭說思不出位；思想越位便隨欲成惡。 |
| 是恰與止善之義背馳。故有位以限其思。有分以制其欲。有德以昭其道。有正以明其守。思發于心。而易徇于情。悖于性。戾于命。逸于分。乖于德。惟以不出位為誡。斯免矣。此彖占無咎。實與艮其背相應。 | 與止善背馳。故以位限思、以分制欲、以德明道、以正守身。思易隨情而悖性命本分，只有不出位才能免，正與彖辭艮背無咎相應。 |
| 悖行既止。順正于性命之原。思念既純。安貞于道德之內。則更何由亂其心。迷于艮哉。故曰艮者限也。限之以位。方止得其所。止者包禁止之義。以位禁止之。則天下皆止于其位。此艮之有成也。艮與坤易位。 | 悖行止、性命正，思想純、道德安貞，心便不亂。艮就是限，以位限制才止得其所；止也含禁止，使天下各止於位，就是艮之成。艮與坤易位。 |
| 故法艮之止。必師坤之安貞。知止為始。安貞為終。一靜永靜。念亦不起。則何患思之出位哉。思指心之所念。心好動而難止。果限其思念。則心亦隨止。此止靜工夫。必自去妄念始。念未必皆妄。而出位之念必為妄。 | 效法艮止也須師坤安貞；知止為始、安貞為終，靜到念不起，怎會思出位？心念好動難止，限制出位妄念，心便止。修止靜從去妄念開始；不是所有念都妄，但越位必妄。 |
| 思不出位。與中庸發皆中節。恰是一理。發皆中節。則情不害性。思不出位。則念不動心。旨哉言乎。明道達德。必從事斯語。 | 思不出位與《中庸》情發中節同理：中節則情不害性，不越位則念不動心。明道達德須實踐此語。 |
| 初六。艮其趾。無咎利永貞。 | 初六：止住腳趾，沒有咎害，利於長久守正。 |

| 此艮初六爻辭也。初六在下。故曰艮其趾。與彖辭艮其背相應。背指合體之背。趾則足之趾。亦背之一部也。如他卦稱趾。不必別其向背。而艮之初。為趾同。為指為跟則異。艮之初六。可釋為足趾之跟。跟猶根也。 | 初六在下，所以說艮趾，與艮背相應。趾是足部，也屬身體背後取象；本注又可解足跟，跟同根，都是立身根本。 |
| 亦從艮。固諧聲。兼會意。謂止于其所。為立定之本。而止于前進。為限制之勢。如以物範之。使勿動也。限其趾。則可知其不行。止其跟。則可見其穩立。不行則無前進之思。穩立亦鮮傾跌之患。是全秉坤安貞之道。 | 『跟』也從艮，既取聲又取止義。止於其所是站穩根本，限制腳趾便不前行，止住足跟便穩立；像以規範約束使它不動。不行便無妄進之念，穩立也少傾跌之患，完全合乎坤的安貞之道。 |
| 厚載之功。而不失其靜定之德者也。故無咎。以初六柔爻剛位。勿用之時。在下而陰柔。宜靜不宜動。如艮之本旨。雖非艮主爻。卻得艮正用。故曰利永貞。以全卦言。不及四德。以初六言。則兼利貞。利貞者。 | 也全厚載靜定，所以無咎。初六柔居剛位，在勿用下位，宜靜不宜動，正合艮用；雖非主爻，卻得正用，所以利永貞。全卦不列四德，初爻則有利貞。 |
| 性情也。在人為重。而實法于地。地先利貞。人道師之。則利永貞。此三字。與坤上六同。坤利永貞。以大其厚載之德。艮利永貞。以明其知止之方。知止而至于永貞。是止于一。止于一。則就于正矣。 | 利貞在人重要而法地，地以利貞為先，人道效法便利永貞，與坤上六辭相近。坤以永貞大厚載，艮以永貞明知止；知止達永貞，就是止於一、歸於正。 |
| 故于利貞二德間。加一永字。永久也。恆久不變。長守不失。方為永貞。永貞以為利。則利自永貞成。雖乾坤貞利平等。而自人道言。則貞為本。利為用。貞為內。利為外。必先貞而後有利。不貞則亦不利。 | 故利貞間加『永』，表示長久不變、守而不失。利由永貞成。從人道看，貞為本內、利為用外，先貞後利，不貞便不利。 |
| 且利出于貞。其利可久可大。為有本也。如人之行。必先知止。行出于止。則行可遠可廣。以有基也。故艮其趾。非徒止之。將以便于行。非徒限之。將以助其進。此共益在下者之志。居卑者之情。不可假也。 | 利出於貞才可久大，如遠行先知止、有根基才廣遠。因此艮趾不只為止，而是便於日後行；限制不是阻礙，而是助進。下位者不能虛假強求。 |
| 不可強也。然必有其道。依其德。遵其時。先立其本。故行者先止。進者有限。皆立本也。本固用宏。不有守。安有為。不能貞。安得利。此利永貞。實艮全卦之道。而于初爻即明示之。初為始。始正則終亦正。 | 必依道德時勢先立本，所以行先止、進有限。本固用宏，無守不能有為，不貞不能得利。利永貞其實是全卦道，初爻先明示；始正則終正。 |
| 始孚于道。則以後咸孚于道。故君子作事謀始。為立本也。艮而在趾。其本已立。如人之立已穩。則舉足成行。此所以為利也。 | 開始合道，後來皆能合道。君子作事謀始正為立本；艮在趾表示根基已立，如人站穩後舉足便行，所以有利。 |
| 象曰。艮其趾。未失正也。 | 象傳說：止住腳趾，是尚未失去正道。 |

| 此艮六二爻辭也。六二坤之正位。而為離中爻。離坎相對應。在身則心與腎主之。艮以背為重。由下而上。初為趾。二為腓。皆足部。腓者腿後肥大部。俗曰腿肚。亦因艮其背。見其所止。止于腓。則可知足之未舉。 | 六二是坤正位，又可為離中爻；在身體取心腎相應。艮由背自下上，初為趾、二為腓。腓是小腿後部；止在腓，可知腳未抬。 |
| 即人之未行。體之未動。體動必先其腓。人行必舉其足。今艮其腓。是全身同止之象。而自限其腿足。不志于行進。則雖能止。究乖于行。雖能靜。卻戾于動。是艮其腓者。不克遂其用。故曰不拯其隨。隨猶遂也。 | 也就是人未行、身未動。身動先用腿，行走要抬足；艮腓使全身止、不志進，雖能止卻違行，雖能靜卻違動，所以不能充分成用，稱不拯其隨。隨也有遂、順義。 |
| 順也。俗稱手足不仁。不用者曰不遂。或作不隨。謂肢體之動。必隨于其心。遂其所志。心命之。志率之。而後動。若無心之命。志之率。而動者。病心。非狂即厥。狂者火之過。厥者水之過。俗稱為風痰。內經曰。 | 手足不能如意動作，俗稱不遂或不隨。肢體應隨心志而動；若無心志命令卻妄動，就是病態。原文以火水過失、風痰等傳統醫理說明。 |
| 風淫末疾。即水火失治。筋脉失主。而搐搦。而牽拘。而促縮。而掉振也。總名之不隨。謂不隨其心志也。六二居中。心志之位。以艮其腓。而失其所止。限其所用。故曰不拯其隨。拯者振拔也。援救也。 | 筋脈失主而抽搐牽拘振動，統稱不隨，即不隨心志。六二居心志中位，卻艮腓、止錯位置、限制作用，所以不拯其隨。拯是振拔救援。 |
| 不拯則不克振作。不能提攜之意。則不得隨其心志。以動以行。又不拯者。不正也。其隨者阿順也。不正而阿順之。是徇其情欲。發于病態。非命之率之之效。則戾于心。故曰其心不快。謂不相應也。二五正位。 | 不拯就是不能振作提攜，肢體不能隨心志行動；也可解不正而只阿順，隨情欲病態而不由正命，便違心，所以心不快、彼此不相應。二五雖正位。 |

| 梗于中者。不能振以升之。阻于內者。不能順以出之。此六二之艮。為非止之所宜。不似初六之趾。猶未失正也。則初六雖在下。卻遠于九三之剛。而柔順其止。可孚于貞守之正。六二以位故。而德不稱。知止之善。 | 中間梗阻，不能振升；內部阻塞，不能順出。六二止在不宜止處，不如初六止趾尚未失正。初六遠九三剛、柔順而止，合貞守；六二雖有位，德不相稱，知道止的善。 |
| 而無以全其守。知行之艱。而無以拯于正。此爻辭以為有所病也。 | 卻不能完整守住；知道行難，也不能救正，所以爻辭指出其病。 |

| 艮為止。而一艮為良。即止于至善之意。良善也。俗稱人善心為良心。孟子以生而知之為良知。生而能之為良能。皆以良即至善。至善者無不善。亦即性善之說所本也。性善者。天性固有之善。不待學問。不以磨練。 | 艮為止，字形加一成『良』，可借解止於至善。良是善，良心、良知、良能都指天性自然固有、不待學習磨鍊的善。 |
| 不關攻琢。自然至善之謂也。而大學稱止于至善。亦即由性善之義。指其歸本還原而已。猶出于性善。復止于至善。始終皆善。則無一不善者存。而要在一止字。則止為體。行為用。不止不行。欲行之至善。 | 《大學》止於至善就是返性善本原。由性善出、復止至善，始終皆善，關鍵在止。止為體、行為用，不止不能善行；要行至善。 |
| 必止于至善。止者定也。歸宿也。志之所在。行亦隨之。旨之所趨。德亦同至。故止能兼行言。而止于至善。亦含有行于至善之意。此止字。即易艮卦之用。艮止。而行亦由艮成。故傳曰成終成始者。莫善于艮。 | 必以至善為歸宿。止有定向歸宿義，志所止、行隨之，德也同至，所以止兼行。艮止而行由之成，故傳說成終成始莫善於艮。 |
| 又曰成言乎艮。艮加一則成良字。此一字即示其所止而已。止于一。方為真止。不一。安有止哉。故一艮。而良善之義具備。大學所謂為人君。止于仁。為人臣。止于敬一節。實亦止于善而已。止于善。則德至而道凝。 | 又說成言乎艮。艮加一成良，這一就表示止於一；不一就不能真止。一艮便具良善。《大學》君仁臣敬等也是各止於善，德至道凝。 |
| 性定而命固。故內功必先止。止于一。則眾念不起。中心永恬。止于中。則百體悠然。精氣圓暢。是止者。道之始終工夫。無論何教何門。不先止。不得道。即不定。不能把持易放之心。幻相紛陳。轉瞬千變。 | 性定命固，所以內修先止。止於一則眾念不起、中心恬然；止於中則身體安和、精氣暢。各家修道都先止，否則心念幻相轉變不定。 |
| 則氣何由靜。精何由凝。神何由聚哉。一念永懷。萬緣同淨。此止也。止而不動。靈明常存。如水之止。如鏡之明。則能縱觀其變。以幻歸真。提約其機。以玄達妙。此有欲而無欲之時也。老氏常有欲以觀其竅。 | 氣不能靜、精不能凝、神不能聚。一念專持、萬緣淨就是止；止而靈明常存，如止水明鏡，才能觀變歸真、掌握玄機。原文以《老子》有欲觀徼作類比。 |
| 即止也。常無欲以觀其妙。即觀也。不止則不能觀。以耳目之聰未除。知識之靈尚亂。則所觀非我之觀物。乃物主我之觀。則心逐物而妄念愈多。靈徇情而無明愈眾。此觀之必先止耳。艮陽在上。一在三爻。一在上爻。 | 無欲觀妙近於觀。不止不能觀，因耳目知識未息時，是物牽我而非我觀物，心逐物、妄念無明愈多，所以觀前必止。艮兩陽分在九三上九。 |
| 三上相應。而位一剛一柔。如二與五。初與四皆是。獨九五與六二為正。乾坤本位也。若初九九四。乃震本爻。初六六四。則巽本爻。而九三上九。艮之本爻。六三上六。兌之本爻。九二九五。坎之本爻。六二六五。 | 三上相應同剛；二五、初四也同類相應。原文整理各卦本爻：初九九四為震，初六六四為巽，九三上九為艮，六三上六為兌，九二九五為坎，六二六五。 |
| 離之本爻。此無論何卦。凡孚此例者。即該各爻本位之用。六子除離坎有同乾坤正位外。其他四卦。皆不得乾坤正位。故後天惟離坎能代乾坤。他不能也。離代乾者。用坤之正。即六二爻。坎代坤者。用乾之正。 | 為離。任何重卦遇這些爻位便帶該卦本用。六子中只有坎離與乾坤正位相合，所以後天惟坎離能代乾坤：離以六二坤正位代乾，坎以九五乾正位代坤。 |
| 即九五爻。可見後天離坎所代者。乾坤之用。非乾坤之體。體陽者用陰。故離代乾。恰同于地天交泰之上卦。而坎代坤。恰同于泰之下卦。坎離代用方孚乾坤本爻本位之德。以後天陰陽不孤立也。孤則不生。 | 可見代的是乾坤之用非體；陽體用陰，所以離代乾如泰上坤，坎代坤如泰下乾。坎離相代才合乾坤本位德，因後天陰陽不能孤立，孤則不生。 |
| 合而後生乃見。艮雖以九三上九。得乾之氣。而六二六五。皆坤之位。初六六四。則巽之位。以一卦備乾坤巽離。凡四卦。其對卦兌。則備坤乾震坎。以陽爻多也。陽爻多者。出于陽而化于陰。反之則陰爻多者。 | 合後才生。艮九三上九得乾氣，六二六五屬坤位，初六六四屬巽位，一卦兼乾坤巽離；對卦兌則兼坤乾震坎。陽爻多者從陽而化陰，反之陰爻多者。 |
| 出于坤而化于乾。艮陽卦也。自坤出。故兩陰在下。下者本始。如震則陽在下。陽為初始。陽氣至盛。故為陽之長。陽至上極。進行已窮。則陽之消。一息一消。互為其根。故震艮往來。如根與枝。兩卦相合。則成離。 | 從坤出而化乾。艮是陽卦卻自坤出，故兩陰在下；下為本始。震陽在下為陽初盛，故長男；艮陽升至極便消。息消互根，所以震艮如根枝互反，合成離。 |
| 是陽之偶。變為陰也。陽奇陰偶故也。如合其半。則為頤。反之為小過。頤得其養。過失其利。故陰不可志于外。陽不可失其初。升降之間。行乃異道。陽升陰降故也。艮之一陽。升已至極。不得不止。故止。 | 陽奇合偶而變陰。兩卦各半合成頤，反為小過；頤得養，小過失利。陰不宜志外、陽不可失初，升降行向不同。艮一陽升極不得不止。 |
| 陽止則反讓陰。全卦皆以止為用。而中爻獨利于行。則以九三六四。孚于既濟。濟則利有攸往。中互雷水解。包震卦之用。震已在上。則雲行雨施。故有潤物之功。而成解緩之德。天道解弛。人事利濟。則艮之用。 | 陽止讓陰，全卦主止，中爻卻利行，因九三六四合既濟，利有攸往；中互雷水解含震用，雷在水上象雲行雨施、潤物解緩。天道舒解、人事得濟，可見艮用。 |
| 豈徒止而已哉。以一陽介兩陰之間。有如坎陷而不終陷。則以原為山也。山本崇高。何長于陷哉。是道之妙用。高者卑之。崇者下之。以劑于平。而非相違也。故艮之道。重在自反。反身而知止。則何往而不宜。 | 不只止。一陽介兩陰像坎陷卻不終陷，因本為高山。妙用是高者自卑、崇者下就以調平，不是矛盾。所以艮重自反，反身知止便無往不宜。 |
| 故艮者退也。退以進。則成功者遠矣。故剛而柔。明而黠。昭昭而不顯。安安而能遷。故曰知止不殆。老氏己深揭其旨矣。 | 艮也有退義，以退為進反能成功久遠；剛中有柔，明而不炫，安而能遷，所以說知止不殆，《老子》已揭此旨。 |
